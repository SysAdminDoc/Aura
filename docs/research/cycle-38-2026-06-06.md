# Cycle 38 - Reddit Provider Source Switch

Date: 2026-06-06

## Research

Reddit is still a user-generated content provider with removal, access, rate,
and app-review obligations under Reddit's current Data API and Developer Terms.
Aura already allowed users to edit wallpaper subreddit lists, but that is not a
runtime source-off control because it does not cover daily picks, scheduled
rotation, repository fetches, or the video wallpaper Reddit feed.

## Local Evidence

- `RedditRepository.kt` owned wallpaper subreddit fetches, subreddit search,
  multi-subreddit aggregation, and the daily top wallpaper helper.
- `WallpapersViewModel.kt` fetched a Reddit-backed daily pick on startup and
  allowed the Reddit tab to load even when no policy-level Reddit switch existed.
- `VideoWallpapersViewModel.kt` attempted Reddit video discovery beside Pexels,
  YouTube, and Pixabay in the shared video wallpaper load path.
- `AutoWallpaperWorker.kt` and `DailyWallpaperWorker.kt` could continue Reddit
  background work independently of visible wallpaper browsing.

## Decision

Add a default-on `reddit_provider_enabled` preference so existing installs keep
their current behavior, then gate every active Reddit entry point behind that
flag. Disabled mode should hide the user-facing Reddit wallpaper tab, skip
background and video discovery work, and record intentional disabled decisions
separately from provider outages.

## Implementation

- Added `PreferencesManager.redditProviderEnabled` and a Settings switch for the
  Reddit source.
- Gated `RedditRepository` before subreddit fetches, search, aggregation, and
  daily-pick lookup.
- Updated Wallpapers so disabled Reddit mode clears daily picks, redirects the
  Reddit tab to Discover, hides Reddit from the tab strip, and avoids Reddit
  loads during refresh/filter transitions.
- Updated Video Wallpapers, Daily Wallpaper, and Auto Wallpaper workers to skip
  Reddit fetch paths when the source is disabled.
- Updated the provider runtime-control matrix to mark Reddit covered by an
  explicit source switch while retaining video subreddit curation as follow-up.

## Verification Plan

- Run focused JVM tests for Wallpapers, Settings, video wallpaper helpers,
  source metrics, and provider runtime controls.
- Run release-compliance Python checks to keep existing legal artifact gates
  green.
- Run `git diff --check` and the changed-line attribution scan before commit.
