# Cycle 63 - Callable Quota Enforcement Contract

## Scope

Cycle 63 converts the community quota design from a policy table plus runbook
into a typed callable contract that backend work can implement without
renaming surfaces or guessing final write paths.

## Primary Sources

- Firebase App Check overview:
  https://firebase.google.com/docs/app-check
- App Check for Cloud Functions:
  https://firebase.google.com/docs/app-check/cloud-functions
- Callable Cloud Functions:
  https://firebase.google.com/docs/functions/callable
- Realtime Database Security Rules:
  https://firebase.google.com/docs/database/security

## Local Evidence

- `CommunityQuotaPolicies` already defines surfaces, daily limits, cooldowns,
  dedupe keys, and required enforcement layers.
- `database.rules.json` already reserves `/community_write_quotas` and
  `/community_write_dedupe` as admin-only namespaces.
- `test/firebase/database.rules.test.mjs` already proves regular clients cannot
  write quota or dedupe ledgers directly.
- Reports, uploads, votes, follows, and profile edits still have direct RTDB
  write paths that should move behind trusted callable mediation before console
  App Check enforcement becomes production reliance.

## Implementation

- Added `CommunityQuotaCallableContract` to the community quota model.
- Added callable function names, payload schema labels, final write paths, and
  limited-use App Check token decisions for reports, sound uploads, wallpaper
  uploads, votes, follows, and profile edits.
- Added `callableWritePaths` so each policy exposes its public writes plus the
  protected quota and dedupe ledger paths.
- Expanded `CommunityQuotaPolicyTest` to verify unique lower-camel callable
  names, required auth/App Check, payload schemas, final write paths, ledger path
  coverage, and replay-token decisions.
- Added `docs/community-callable-quota-enforcement.md` with request envelope,
  backend transaction sequence, error mapping, Android migration order, and
  verification plan.
- Linked the callable contract from the quota, App Check, and community
  reporting runbooks.
