# Cycle 70 - Block User Repository Filtering

## Scope

Cycle 70 implements the first runtime block-user filtering slice. It adds an
Android repository for the private block list, block/unblock write helpers, and
client-side filtering for community sound feeds, community wallpaper feeds, and
creator profile dashboard lists.

## Primary Sources

- Google Play User Generated Content policy:
  https://support.google.com/googleplay/android-developer/answer/9876937
- Google Play moderation requirements for UGC apps:
  https://support.google.com/googleplay/android-developer/answer/12923286
- Firebase Realtime Database Android read/write documentation:
  https://firebase.google.com/docs/database/android/read-and-write
- Firebase Realtime Database Security Rules:
  https://firebase.google.com/docs/database/security

## Local Evidence

- Cycle 68 reserved `/community_user_blocks/{blockerUid}/{blockedUid}` and
  `/community_blocked_by/{blockedUid}/{blockerUid}` with RTDB rules coverage.
- No Android repository read/write path existed for those block rows.
- Public community feeds were not filtering uploads by private block state.
- Filtering should not create a Firebase anonymous identity for users who only
  browse public community content.

## Implementation

- Added `CommunityBlockRepository` with:
  - live private block-list reads when a Firebase UID already exists;
  - one-shot private block-list reads for suspend repository fetches;
  - block writes that maintain the private list plus admin reverse index;
  - unblock writes that remove both rows.
- Added `CommunityIdentityProvider.currentFirebaseUid()` so filtering can
  avoid signing in solely to read a private block list.
- Added reusable block helper functions in `CommunityBlockPolicy.kt` for
  unblock updates, normalized block IDs, and uploader matching against legacy
  `uploaderId` plus canonical `uploaderUid`.
- Updated `UploadRepository.getCommunityUploads()` to hide blocked uploaders
  and re-emit the current snapshot when the private block list changes.
- Updated `WallpaperUploadRepository.getCommunityWallpapers()` to hide blocked
  uploaders during community wallpaper fetches.
- Updated `CreatorProfileRepository` to filter blocked creators from top
  creators, followed creators, and followed uploads.
- Added focused JVM tests for unblock updates, blocked uploader matching, and
  creator upload filtering.
