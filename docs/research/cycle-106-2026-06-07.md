# Cycle 106 - Sound Upload Callable Emulator Coverage

## Goal

Extend the RTDB-emulator-backed callable handler persistence lane from profile,
report, vote, follow, and block writes to community sound upload finalization.

## Research

- `finalizeCommunitySoundUpload` writes public metadata under
  `/community_sounds/{uploadId}` and owner index rows under
  `/owner_uploads/{uid}/sounds/{uploadId}`.
- Sound upload dedupe is derived from the normalized Storage path, so the same
  committed blob path should be idempotent before another quota mutation.
- The focused Functions test already verifies metadata normalization,
  storage-path ownership, storage-path dedupe, cooldown, daily-limit, Auth, and
  App Check behavior using a fake backend.

## Implementation

- Added `test/firebase/functions.sound-upload.test.mjs`.
- Updated `finalizeCommunitySoundUploadHandler()` to default to its real
  Firebase Admin SDK backend when no fake backend is passed.
- The sound upload emulator test verifies:
  - accepted public metadata writes under `/community_sounds/{uploadId}`;
  - owner index writes under `/owner_uploads/{uid}/sounds/{uploadId}`;
  - server-derived uploader UID, upload ID, timestamps, rights timestamp, and
    zero-vote initialization;
  - quota rows under `/community_write_quotas/{uid}/{yyyyMMdd}/sound_uploads`;
  - storage-path dedupe markers under
    `/community_write_dedupe/{uid}/sound_uploads/{dedupeKey}`; and
  - same-storage-path idempotency before additional quota mutation.
- Refreshed `docs/community-backend-manifest.json`.
- Updated roadmap, changelog, completed log, backend runbook, callable quota
  enforcement doc, and loop state.

## Remaining Risk

This is RTDB-emulator-backed handler persistence coverage, not a Firebase
callable wire-protocol test. Wallpaper uploads still need the same persistence
lane, and all surfaces still need full callable protocol coverage, Android
migration, owner-approved deploy evidence, Firebase Console App Check evidence,
and direct RTDB rule tightening.

## Next

- Add RTDB-emulator-backed handler persistence coverage for wallpaper uploads.
- Add full callable wire-protocol coverage when Auth/App Check emulator wiring
  is available.
- Add Android callable adapters for reports, votes, follows, user blocks,
  upload metadata finalization, and profile edits.
