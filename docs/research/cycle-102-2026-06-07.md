# Cycle 102 - Report Callable Emulator Coverage

## Goal

Extend the RTDB-emulator-backed callable handler persistence lane from profile
edits to community reports.

## Research

- `submitCommunityReport` writes one public moderation intake row under
  `/community_reports/{reportId}` plus quota and dedupe ledgers.
- The focused Functions test already verifies report payload validation,
  duplicate handling, cooldown, daily-limit, Auth, and App Check behavior using
  a fake backend.
- The Cycle 101 emulator lane proved the same handler-core pattern can run
  against the real Admin SDK backend with the RTDB emulator.

## Implementation

- Added `test/firebase/functions.report.test.mjs`.
- Updated `submitCommunityReportHandler()` to default to its real Firebase
  Admin SDK backend when no fake backend is passed.
- Expanded `npm run test:functions-emulator` from the profile-only test file to
  all `test/firebase/functions.*.test.mjs` files.
- The report emulator test verifies:
  - accepted report writes under `/community_reports/{reportId}`;
  - server-derived reporter UID and reported timestamp;
  - quota rows under `/community_write_quotas/{uid}/{yyyyMMdd}/reports`;
  - dedupe markers under `/community_write_dedupe/{uid}/reports`; and
  - same-content/same-reason idempotency through emulator-backed dedupe.
- Refreshed `docs/community-backend-manifest.json`.
- Updated roadmap, changelog, completed log, and loop state.

## Verification

- `npm run test:functions-emulator`
- `npm run test:functions`
- `py -3 tools\community_backend_manifest.py --mode check`
- `py -3 tools\community_callable_contract_check.py --contract docs\community-callable-contract.json`
- `npm --prefix functions audit --audit-level=high`
- `git diff --check`

## Remaining Risk

This is RTDB-emulator-backed handler persistence coverage, not a Firebase
callable wire-protocol test. Votes, follows, blocks, sound uploads, and
wallpaper uploads still need the same persistence lane, and all surfaces still
need full callable protocol coverage, Android migration, owner-approved deploy
evidence, Firebase Console App Check evidence, and direct RTDB rule tightening.

## Next

- Add RTDB-emulator-backed handler persistence coverage for votes, follows,
  user blocks, sound uploads, and wallpaper uploads.
- Add full callable wire-protocol coverage when Auth/App Check emulator wiring
  is available.
- Add Android callable adapters for reports, votes, follows, user blocks,
  upload metadata finalization, and profile edits.
