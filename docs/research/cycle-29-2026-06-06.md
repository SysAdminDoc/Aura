Date: 2026-06-06

## Objective

Give users a clear Settings path to the generated release notice evidence without adding the stock Google OSS notice runtime dependency or replacing Aura's content-source provider disclosures.

## Local Evidence

- `LicensesScreen.kt` listed manual library rows and content-source provider disclosures.
- `SettingsScreen.kt` linked to the licenses screen with the subtitle "See library licenses and content-source attributions."
