# Cycle 143 - Local Storage Data Safety Gate

## Research

Google Play Data safety guidance says developers must describe collection,
sharing, and security practices, and it treats third-party transfer from app
libraries, SDKs, or on-device transfers to another app as sharing. The same
guidance distinguishes data that stays only on the device from off-device
collection, so Aura's release matrix needs to separate local-only stores from
Firebase/provider submission and user-directed share/export flows.

Aura already has the permission and network endpoint slices of the Data safety
matrix. The remaining checkable gap was app-private local storage: settings,
Room state, identity/vote preferences, crash diagnostics, media caches,
generated wallpaper files, offline favorites, live-wallpaper media, and
temporary share/recording artifacts.

## Local Evidence

- `PreferencesManager.kt` stores provider keys, source switches, scheduler
  settings, generated-content disclosure state, and live-video runtime prefs.
- `Database.kt` and `AppModule.kt` define the Room database `freevibe.db` for
  favorites, downloads, search history, wallpaper cache metadata, wallpaper
  history, and collections.
- `backup_rules.xml` and `data_extraction_rules.xml` exclude DataStore,
  weather/live-wallpaper prefs, crash logs, and Room sidecars, but not the main
  Room DB or several identity/widget/runtime SharedPreferences files.
- `FreeVibeApp.kt` and `CrashDiagnosticsCollector.kt` write and sanitize the
  app-private `crash.log`; sharing requires explicit user action.
- `AiWallpaperRepository.kt`, `OfflineFavoritesManager.kt`,
  `AuraOriginalsDownloader.kt`, `VideoWallpaperStorage.kt`,
  `CommunityAudioRecorder.kt`, and `CollectionExporter.kt` write app-private
  or cache-backed media/share artifacts with different deletion and backup
  postures.

## Implementation

- Extended `docs/privacy/data-safety.json` with `localStorageSurfaces`.
- Added 12 reviewed rows covering DataStore, Room, community identity/vote
  prefs, widget/selection prefs, live wallpaper prefs/media, crash diagnostics,
  Coil/audio caches, offline favorites, generated wallpapers, community
  recording temp files, share-out temp files, and Aura Originals files.
- Extended `tools/privacy_data_safety_check.py` to require every local storage
  row to include data types, collection/sharing status, user control, retention,
  deletion path, backup status, and existing source-file paths.
- Extended `docs/privacy/data-safety.md` with a Local Storage Ledger and release
  checklist language for source path and backup-rule drift.
- Added focused unit tests for missing source files, missing Markdown rows, and
  unsupported backup statuses.

## Verification

  passed with 15 permissions, 15 network surfaces, and 12 local storage

  passed.
- `py -3 -m unittest discover -s test/tools -p '*_test.py'` passed: 194 tests.
