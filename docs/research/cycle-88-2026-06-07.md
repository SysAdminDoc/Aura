# Cycle 88 - Account Deletion Web URL Gate

## Scope

Add a local publication gate for the hosted account deletion web URL so Aura can
track the current pending owner-publication state without pretending a live URL
exists.

## Sources

- Google Play account deletion requirements:
  https://support.google.com/googleplay/android-developer/answer/13327111
- Google Play User Data policy account deletion requirement:
  https://support.google.com/googleplay/android-developer/answer/10144311
- Existing web-intake contract:
  `docs/support/community-account-deletion-web-intake.md`

## Local Evidence

- Aura already has an in-app Settings > Community identity request-code path
  and a private hosted-form intake validator.
- The repository did not have a privacy policy or durable source of truth for
  whether the required external deletion web resource has been published.
- A placeholder URL in committed docs would create false Play submission
  evidence. The safer interim state is an explicit `pendingOwnerUrl` manifest
  that must fail if a URL is filled before the policy/support docs reference it.

## Implementation

- Added `docs/privacy/privacy-policy.md` with Aura data categories, no-ads and
  no-tracking statements, deletion handling boundaries, retained-record
  disclosure, and pending owner publication status for the hosted deletion URL.
- Added `docs/support/community-account-deletion-web-url.json` as the canonical
  hosted deletion URL publication manifest.
- Added `tools/community_deletion_web_url_check.py` to validate the pending and
  published manifest states.
- Added `test/tools/community_deletion_web_url_check_test.py` for pending,
  published, missing-link, and non-HTTPS cases.
- Wired the validator and manifest into the backend-sensitive CI path.
- Updated support, policy, backend runbook, roadmap, changelog, completed
  ledger, and loop state docs.

## Verification

- `py -3 -m py_compile tools\community_deletion_web_url_check.py test\tools\community_deletion_web_url_check_test.py`
- `py -3 tools\community_deletion_web_url_check.py --manifest docs\support\community-account-deletion-web-url.json --repo-root .`
- `py -3 -m unittest discover -s test/tools -p '*_test.py'`

## Remaining Work

- Owner must publish an HTTPS deletion request page before Play production
  submission, set the manifest status to `published`, and reference the URL
  from both the privacy policy and web-intake support document.
- Execute Firebase Auth deletion only through the owner-approved private Auth
  package path.
- Execute public upload deletion only through the owner/admin upload workflow
  after a clean upload plan has no blocked rows.
