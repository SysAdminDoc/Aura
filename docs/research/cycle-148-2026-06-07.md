# Cycle 148 - Release Metadata Consistency Gate

## Scope

Cycle 148 started after the alternative-store disclosure gate landed. Owner
access for live callable evidence, hosted deletion URL publication, production
Firebase dry runs, GitHub security settings evidence, signed release dry-run
evidence, and fresh screenshots remained unavailable locally. This pass
completed the next checkable release-readiness item: keeping app package/version
metadata, Fastlane store text, README links, privacy URLs, distribution packets,
release preflights, and expected release artifacts aligned.

## Research Finding

Release metadata is split across Play/Fastlane store text, GitHub Release
artifacts, README links, privacy docs, and alternative-store packets. Official
store/release docs continue to rely on current title/description/changelog text,
artifact retention, and screenshot/graphics readiness. Aura already had
individual gates for store metadata, privacy links, Play App content, and
alternative-store disclosures, but no single check proved those release-facing
surfaces still agreed on package identity, version, privacy URL, commands, and
artifact expectations.

## Local Evidence

- `app/build.gradle.kts` currently declares `com.freevibe`, `6.31.1`, and
  `versionCode 112`.
- Fastlane metadata has title, short description, full description, and
  `changelogs/112.txt`.
- README links release signing, channel strategy, alternative-store disclosure,
  developer verification, and supply-chain docs.
- Release docs already list the store, privacy, Data safety, community
  guidelines, Play App content, alternative-store, and bundle validation gates.

## Implementation

- Added `docs/distribution/release-metadata-consistency.md` as the
  owner-facing release metadata consistency packet.
- Added `docs/distribution/release-metadata-consistency.json` as the checked
  machine contract for package/version metadata, Fastlane paths, privacy URL,
  README links, preflight commands, release artifact names, evidence paths, and
  source URLs.
- Added `tools/release_metadata_consistency_check.py` to validate Gradle
  package/version values, Fastlane title/description/changelog text, README
  links, privacy URL alignment, Play and alternative-store packet package names,
  release workflow snippets, release docs, and expected artifact mentions.
- Added focused backend tests for the live packet, version mismatch, missing
  README link, missing release preflight command, and privacy URL mismatch.
- Wired the gate into verify and release workflows before Android build work.
- Updated release dry-run, release signing, supply-chain, README, research,
  roadmap, changelog, completion, and loop-state docs.
