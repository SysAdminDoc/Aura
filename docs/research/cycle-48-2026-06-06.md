# Cycle 48 - Provider Removal Failure Reconciliation

## Scope

Cycle 48 implements the next source-deletion slice after Cycle 46 added
persisted unavailable-source state and Cycle 47 completed Pexels enhancement
guardrails. The target is automatic saved-item reconciliation when a provider
fetch proves that the upstream media is gone.

## Local Evidence

- `FavoriteEntity` and `DownloadEntity` already persist
  `sourceAvailability`/`sourceAvailabilityReason`.
- Favorites, Downloads, wallpaper detail, and sound detail already show
  "Source unavailable" and hide live-source affordances when those fields are
  set.
- `WallpaperApplier`, `SoundApplier`, and `DownloadManager` surface explicit
  provider failures such as 404 or 410 through exception messages.
- Before this cycle, those failures were shown as transient errors only; saved
  favorites/download rows were not reconciled to `SOURCE_UNAVAILABLE`.

## Implementation

- Added `SourceAvailabilityPolicy.kt` with a shared classifier for explicit
  remote-gone signals: 404, 410, content not found, not found, gone, removed,
  or deleted.
- Added provider-specific reasons for Reddit, Pexels, Pixabay, YouTube,
  Community, Freesound, SoundCloud, and generic sources.
- Updated wallpaper apply and download failures to mark matching favorites
  unavailable when the failure proves upstream removal.
- Updated sound apply and download failures to mark matching favorites
  unavailable on the same explicit removed/gone signals.
- Updated `DownloadManager` to mark matching download-history rows unavailable
  when a re-download fails with a removed/gone signal.

## Verification

Passed:

$env:JAVA_HOME='C:/Program Files/Android/Android Studio/jbr'; $env:ANDROID_HOME="$env:USERPROFILE/AppData/Local/Android/Sdk"; .\gradlew.bat --no-daemon --max-workers=2 :app:testDebugUnitTest --tests com.freevibe.data.model.SourceAvailabilityPolicyTest --tests com.freevibe.ui.screens.wallpapers.WallpapersViewModelTest --tests com.freevibe.ui.screens.sounds.SoundsViewModelTest

The focused tests prove:

- 404/410/removed/deleted signals map to provider-specific unavailable reasons.
- Transient failures such as HTTP 500 and socket timeouts are ignored.
- Wallpaper download failures mark saved favorites unavailable with the Pexels
  reason.
- Sound download failures mark saved favorites unavailable with the Freesound
  gone reason.
