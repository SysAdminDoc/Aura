# Cycle 133 - Generated Wallpaper Disclosure Gate

## Scope

Cycle 133 implemented the prompt/privacy disclosure gate for generated
wallpapers. Owner-gated live callable, hosted deletion URL, production
Firebase, GitHub settings, and release-secret dry-run evidence remained
unavailable locally.

## Policy Check

The current Google Play AI-generated content policy says generative apps must
avoid restricted content and include in-app reporting or flagging for offensive
generated content. This pass addressed the separate roadmap disclosure gate:
prompt sharing, provider key/credit use, local storage, and Settings review.
The generated-content report path remains the next local policy item.

## Implementation

- Added a DataStore-backed `generated_content_disclosure_accepted` preference.
- Added ViewModel request gating so generation requires provider enabled,
  prompt, Stability key, and disclosure acceptance before repository calls.
- Added a generated wallpaper disclosure dialog in the generation flow.
- Added Settings > API Keys > Generated wallpaper disclosure for review/reset.
- Added `docs/privacy/ai-generation.md` and linked it from the privacy policy.
- Updated roadmap, changelog, completion, and loop-state docs.
