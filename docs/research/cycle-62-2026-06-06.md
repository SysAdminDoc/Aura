# Cycle 62 - Closed Report Review Filters

## Scope

Cycle 62 exposes status filters in the admin community report queue so admins
can review hidden, dismissed, and restored reports after the open queue is
cleared.

## Primary Sources

- Firebase Realtime Database Android read/write data:
  https://firebase.google.com/docs/database/android/read-and-write
- Firebase DatabaseReference API:
  https://firebase.google.com/docs/reference/android/com/google/firebase/database/DatabaseReference
- Firebase Realtime Database Security Rules:
  https://firebase.google.com/docs/database/security

## Local Evidence

- `CommunityReportRepository.reports(status, limit)` already queries
  `/community_reports` by indexed `status`.
- `database.rules.json` already restricts report reads to custom-claim admins
  and indexes `status`.
- Cycles 60 and 61 added private takedown/delete receipts, making closed-report
  history more useful for moderation review and retry follow-up.

## Implementation

- Added `selectedStatus` state to `CommunityReportsViewModel`.
- Switched the admin report feed to `flatMapLatest` over the selected status so
  the same screen can load Open, Hidden, Dismissed, or Restored queues.
- Added status filter chips to the report screen, including the empty state, so
  admins can reach closed queues even when no open reports exist.
- Added ViewModel coverage proving status selection switches from the open feed
  to the hidden feed.
- Updated the community reporting runbook and continuation state.
