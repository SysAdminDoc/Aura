# Cycle 33 - Custom In-App Generated Dependency Notice Viewer

Date: 2026-06-06

## Objective

Add a current-toolchain in-app viewer for generated Google OSS dependency
notices without adding the stock Play services OSS licenses runtime dependency
that previously caused release-runtime convergence risk.

## Local Evidence

- `app/build/generated/res/releaseOssLicensesTask/raw/third_party_license_metadata`
  exists after the Google OSS task and contains metadata rows in
  `offset:length name` format.
- `app/build/generated/res/releaseOssLicensesTask/raw/third_party_licenses`
  contains the notice text bytes referenced by those metadata ranges.
- The release metadata currently has 288 generated notice rows.
- `LicensesScreen.kt` already exposed release artifact links plus manual library
  and content-source rows, but it did not read the generated raw resources
  inside the app.

## Source Review

Primary sources reviewed:

- Google Play services open source notices:
  `https://developers.google.com/android/guides/opensource`
- Google Play services OSS licenses API reference:
  `https://developers.google.com/android/reference/com/google/android/gms/oss/licenses/package-summary`

Google documents the plugin plus SDK as a path for collecting and displaying
open-source notices, and the stock SDK exposes an `OssLicensesMenuActivity`.
Aura keeps the plugin-generated raw resources but avoids adding the SDK runtime
dependency for now because earlier cycles found dependency convergence risk from
`play-services-oss-licenses`.

## Implementation

Added `GeneratedDependencyNotices.kt`:

- Reads `R.raw.third_party_license_metadata` and `R.raw.third_party_licenses`.
- Parses Google OSS metadata rows into offset, length, and dependency name.
- Slices the license bytes by metadata range.
- Infers compact display labels for common generated notice forms such as
  Apache 2.0, MIT, BSD-3-Clause, and GPL-3.0.
- Safely returns an empty list if generated resources are unavailable.

Updated `LicensesScreen.kt`:

- Loads generated dependency notices from raw resources.
- Adds a `Generated Dependencies` section before manual library rows.
- Shows generated dependency names and inferred license labels in-app.
- Opens the full generated notice text in a selectable dialog.
- Keeps release artifact links, manual library rows, and provider disclosure
  rows visible.

Updated `LicensesScreenTest`:

- Keeps coverage for release artifact links.
- Adds parser coverage for metadata ranges, label inference, license text
  slicing, and invalid-range skipping.

## Result

Cycle 33 ships a custom in-app generated dependency notice viewer that reuses
the existing plugin-generated raw resources. It avoids the stock Play services
notice runtime while giving users and release owners direct access to generated
dependency notice rows in Settings.

## Remaining Risk

The viewer is intentionally simple. The next improvement should add search,
filtering, and high-risk overlay alignment so release owners can find specific
generated dependencies without scrolling the full generated list.
