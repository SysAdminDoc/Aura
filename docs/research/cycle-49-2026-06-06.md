# Cycle 49 - Sound License Capability Gates

## Scope

Cycle 49 implements the first action-level sound license capability slice after
Cycles 46-48 added saved-source availability state and remote-removal
reconciliation. The goal is to stop treating a license badge as sufficient and
instead gate sound actions by source, normalized license, provenance metadata,
and source availability.

## Local Evidence

- `Sound` already carries `source`, `license`, `uploaderName`, and
  `sourcePageUrl`.
- `SoundDetailScreen` showed source/uploader/license badges, but apply,
  download, trim, contact assignment, and share actions were not license-aware.
- `SoundsViewModel.applySound()` and `downloadSound()` resolved remote streams
  before any license/source action decision.
- `FavoriteEntity` preserved uploader/source-page metadata for saved sounds but
  did not persist `license`, so restored favorites could lose the policy input.
- `ContactPickerViewModel` had a separate ringtone-assignment apply path.

## Implementation

- Added `SoundLicensePolicy.kt` with normalized sound license labels and action
  capabilities for apply, download, share, edit/trim, and Aura Originals use.
- Added source-specific decisions:
  - YouTube apply/download require confirmation; edit and Aura Originals use are
    disabled.
  - SoundCloud apply/download/edit/Aura Originals use are disabled until source
    permissions are reviewed; link sharing remains allowed when a source page is
    present.
  - CC BY-NC variants require confirmation for apply/download/edit and cannot be
    included in Aura Originals.
  - No-derivatives variants disable edit/trim and Aura Originals use.
  - Missing remote license metadata and unavailable sources disable live-source
    actions.
- Updated `SoundsViewModel` to enforce apply/download gates before stream
  resolution or download work starts.
- Updated `SoundDetailScreen`, quick apply, and contact assignment to share the
  same disabled/confirmation behavior.
- Updated share text so sound shares include name, creator, source, normalized
  license, and source link.
- Added a nullable `license` field to `FavoriteEntity`, Room schema v16, and a
  v15-to-v16 migration.
- Updated sound favorite mapping and favorites export/import so saved sound
  licenses survive restore/export paths.
- Added `docs/legal/sound-license-capabilities.md` as the human-readable matrix.

Focused tests prove:

- CC0 bundled sounds allow reviewed Aura Originals actions.
- YouTube requires confirmation for apply/download and disables edit/bundle.
- SoundCloud is link-only until permissions are reviewed.
- CC BY-NC requires confirmation for apply/download/edit and disables bundling.
- Missing remote license metadata disables live-source actions.
- Saved sound favorites and favorites imports preserve license metadata.
- Unconfirmed YouTube download calls stop before stream resolution.
