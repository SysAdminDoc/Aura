# Cycle 140 - Privacy Policy Link Gate

## Scope

Cycle 140 closed the public privacy-policy link and in-app link slice from the
store-readiness queue. Owner-gated live callable evidence, hosted deletion URL
publication, production Firebase dry runs, GitHub security settings evidence,
signed release dry-run evidence, and fresh store screenshots remained
unavailable locally.

## Current Finding

Google Play's User Data policy still requires every app to post a privacy
policy link in Play Console and a privacy-policy link or text inside the app.
Google's Data safety guidance also says developers must complete the form and
provide a privacy-policy link. Aura had a tracked privacy policy and Fastlane
metadata URL, but Settings > About exposed source and licenses only.

## Implementation

- Added Settings > About > Privacy policy, opening the public policy URL:
  `https://github.com/SysAdminDoc/Aura/blob/main/docs/privacy/privacy-policy.md`.
- Added a README privacy section pointing to the same public policy URL.
- Added `docs/privacy/privacy-policy-link.json` as the checked link contract.
- Added `tools/privacy_policy_link_check.py` to validate that the URL remains
  HTTPS and appears in Settings, README, Fastlane metadata, release workflows,
  and release dry-run docs.
- Wired the privacy-link gate into verify and release workflows before Android
  setup or signed APK assembly.
- Updated the release workflow security policy, release signing docs, release
  dry-run docs, and supply-chain docs so the release preflight cannot silently
  lose the privacy-link gate.
- Added focused backend tests for the live contract, non-HTTPS URLs, missing
  Settings links, missing Fastlane links, incomplete privacy policy terms,
  missing release workflow gates, and non-Google policy source URLs.

## Verification

- `py -3 tools\privacy_policy_link_check.py --policy docs\privacy\privacy-policy-link.json --repo-root .`
- `py -3 -m unittest discover -s test/tools -p '*_test.py'`
