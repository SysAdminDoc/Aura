# Cycle 50 - Community Upload Rights Metadata

## Scope

Cycle 50 implements the first community upload rights-attestation slice for
sounds and wallpapers. The goal is to stop publishing community media without a
selected license, explicit rights confirmation, and optional source URL
metadata.

## Local Evidence

- `UploadRepository.uploadSound()` wrote public sound metadata with uploader
  identity and file data, but no selected license or attestation field.
- `WallpaperUploadRepository.uploadWallpaper()` had the same gap for community
  wallpapers.
- The sound policy added in Cycle 49 still had to treat community rows without
  license metadata as generic `User Upload` content.
- Upload dialogs could start a public upload after only name/category/tag input.
- `database.rules.json` did not require rights metadata for community upload
  records.

## Implementation

- Added `CommunityUploadRights.kt` with selected-license normalization,
  attestation validation, and optional HTTPS source URL validation.
- Added `CC0`, `CC BY`, and `CC BY-NC` license choices plus a rights
  confirmation checkbox and optional source URL field to sound and wallpaper
  upload dialogs.
- Updated `SoundsViewModel`, `WallpapersViewModel`, `UploadRepository`, and
  `WallpaperUploadRepository` so upload paths validate rights metadata before
  media upload work begins.
- Stored `uploaderUid`, `license`, `rightsAttested`, `rightsAttestedAt`, and
  `sourceUrl` for new community sound and wallpaper rows.
- Updated community sound feed mapping so selected license/source metadata feeds
  the sound action policy, while legacy rows continue to use the `User Upload`
  fallback.
- Added wallpaper `license` model/favorite mapping preservation and surfaced
  community wallpaper license metadata on detail and more-actions surfaces.
- Updated RTDB rules to require license, true attestation, attestation
  timestamp, authenticated uploader UID, and blank-or-HTTPS source URL metadata
  for community sound and wallpaper records.
- Added `docs/legal/community-upload-rights.md` and updated the sound license
  capability matrix.
