# Cycle 105 - User Block Callable Emulator Coverage

## Goal

Extend the RTDB-emulator-backed callable handler persistence lane from profile,
report, vote, and follow writes to community user block state changes.

## Research

- `setCommunityUserBlock` writes or removes private block rows under
  `/community_user_blocks/{uid}/{blockedUid}` and admin reverse-index rows
  under `/community_blocked_by/{blockedUid}/{uid}`.
- Block and unblock use separate dedupe keys because they are opposite state
  transitions for the same blocked user.
- The focused Functions test already verifies payload normalization,
  self-block rejection, no-op idempotency, same-state dedupe, cooldown,
  daily-limit, Auth, and App Check behavior using a fake backend.

## Implementation

- Added `test/firebase/functions.block.test.mjs`.
- Updated `setCommunityUserBlockHandler()` to default to its real Firebase
  Admin SDK backend when no fake backend is passed.
- The block emulator test verifies:
  - accepted block writes under `/community_user_blocks/{uid}/{blockedUid}`;
  - matching reverse-index writes under `/community_blocked_by/{blockedUid}/{uid}`;
  - server-derived blocker UID and created timestamp;
  - quota rows under `/community_write_quotas/{uid}/{yyyyMMdd}/user_blocks`;
  - block dedupe markers under
    `/community_write_dedupe/{uid}/user_blocks/{blockedUid}_block`;
  - accepted unblock removes private and reverse rows; and
  - missing-unblock idempotency before quota mutation.
- Refreshed `docs/community-backend-manifest.json`.
- Updated roadmap, changelog, completed log, backend runbook, callable quota
  enforcement doc, and loop state.

## Remaining Risk

This is RTDB-emulator-backed handler persistence coverage, not a Firebase
callable wire-protocol test. Sound uploads and wallpaper uploads still need the
same persistence lane, and all surfaces still need full callable protocol
coverage, Android migration, owner-approved deploy evidence, Firebase Console
App Check evidence, and direct RTDB rule tightening.

## Next

- Add RTDB-emulator-backed handler persistence coverage for sound uploads and
  wallpaper uploads.
- Add full callable wire-protocol coverage when Auth/App Check emulator wiring
  is available.
- Add Android callable adapters for reports, votes, follows, user blocks,
  upload metadata finalization, and profile edits.
