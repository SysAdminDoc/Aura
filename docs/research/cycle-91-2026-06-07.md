# Cycle 91 - Callable Contract Manifest Gate

## Scope

Make the Cycle 63 community callable quota contract machine-checkable before a
deployable Cloud Functions project is added.

## Sources

- Cloud Functions callable functions:
  https://firebase.google.com/docs/functions/callable
- Callable protocol and Auth/App Check request context:
  https://firebase.google.com/docs/functions/callable-reference
- App Check for Cloud Functions:
  https://firebase.google.com/docs/app-check/cloud-functions
- Android code contract:
  `app/src/main/java/com/freevibe/data/model/CommunityQuotaPolicy.kt`

## Local Evidence

- `CommunityQuotaPolicies` already defines seven community write surfaces with
  callable names, payload schemas, final write paths, limited-use App Check
  settings, and protected quota/dedupe ledger paths.
- The backend docs had a table, but there was no JSON manifest that a future
  Cloud Functions implementation or deploy checklist could validate.
- `docs/community-quota-rate-limits.md` still listed quota reset timezone as an
  implementation gap. The backend manifest can close that by pinning quota days
  to UTC until a deliberate policy change is made.

## Implementation

- Added `docs/community-callable-contract.json` with all seven callable surfaces,
  protected ledger paths, function names, payload schemas, final write paths,
  App Check/Auth requirements, limited-use App Check decisions, and UTC quota
  day boundary.
- Added `tools/community_callable_contract_check.py` to validate the manifest
  against the Android quota policy constants.
- Added `test/tools/community_callable_contract_check_test.py` for the valid
  manifest summary plus missing surface, duplicate function name, limited-use
  App Check drift, and ledger namespace drift failures.
- Wired the manifest check into the backend-sensitive CI path.
- Updated callable quota docs, backend runbook, roadmap, changelog, completed
  ledger, and loop state docs.

## Verification

- `py -3 -m py_compile tools\community_callable_contract_check.py test\tools\community_callable_contract_check_test.py`
- `py -3 -m unittest discover -s test/tools -p 'community_callable_contract_check_test.py'`
- `py -3 tools\community_callable_contract_check.py --contract docs\community-callable-contract.json`
- `py -3 -m unittest discover -s test/tools -p '*_test.py'`
