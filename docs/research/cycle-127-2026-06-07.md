# Cycle 127 Research - Redacted URL And Request Logging Contract

## Goal

Keep authenticated provider URLs and header values out of support surfaces that
users can view, copy, or paste into issue reports.

## Local Evidence

- `SourceMetrics.recordFailure()` stored `error.message?.take(200)` directly.
  Settings renders that text in the source diagnostics card as the last provider
  error detail for the current app session.
- `CrashDiagnosticsText.sanitize()` already redacted provider-shaped secrets in
  crash log tails, but the secret grammar lived only in crash diagnostics.
- Aura provider requests use query credentials for Wallhaven, Pixabay,
  Freesound, and SoundCloud. Pexels and Stability use `Authorization` headers.
- SoundCloud constructs authenticated stream URLs with `client_id` for playback,
  so any thrown message containing those URLs must be redacted before reaching
  metrics or support bundles.

## Implementation

- Added `RequestRedactor` as the shared request redaction contract.
- `RequestRedactor.redact()` redacts bearer headers, bare bearer tokens,
  provider query values (`apikey`, `key`, `token`, `client_id`, and related
  names), and assignment-style provider credentials including dotted
  `local.properties` names.
- `RequestRedactor.formatRequest()` renders method, host/path, redacted query,
  and optional status code while omitting scheme and fragment text.
- `CrashDiagnosticsText.sanitize()` now delegates provider secret redaction to
  `RequestRedactor` after app-private path and file URI redaction.
- `SourceMetrics.recordFailure()` now redacts error messages before storing the
  200-character snapshot text displayed in Settings.
- Updated crash diagnostics support docs to document that the same request
  redactor protects in-app source diagnostics.

## Verification

```powershell
.\gradlew.bat --no-daemon --max-workers=2 ":app:testDebugUnitTest" --tests "com.freevibe.service.RequestRedactorTest" --tests "com.freevibe.service.SourceMetricsTest" --tests "com.freevibe.service.CrashDiagnosticsTextTest" --stacktrace
```

Result: passed.

## Remaining Risk

- Provider repositories still have to construct authenticated request or stream
  URLs where the upstream API requires query credentials. This pass prevents
  those values from leaking through the current metrics and crash diagnostics
  support surfaces, but it does not replace every provider's transport-level
  authentication model.
- The broader endpoint inventory runbook remains open and should enumerate
  auth location, cache policy, and release owner for every network surface.
