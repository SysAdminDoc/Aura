## Executive Summary

Cycle 23 turns the native/copyleft compliance gap from Cycle 22 into a release artifact.

Implemented in the real repo:

- `tools/native_compliance_inventory.py` inventories resolved Gradle cache artifacts for youtubedl-android common/library/ffmpeg and NewPipeExtractor coordinates.
- `docs/legal/native-compliance.md` records artifact hashes, payload paths, nested yt-dlp/Python facts, QuickJS entries, FFmpeg ABI payload entries, source/build references, and release review notes.
- `.github/workflows/release.yml` now generates `NATIVE-COMPLIANCE.md`, includes it in `SHA256SUMS.txt`, uploads it as a workflow artifact, and attaches it to tagged GitHub Releases.
- `docs/distribution/supply-chain.md` now treats the native compliance packet as release evidence beside the APK and `THIRD-PARTY-NOTICES.md`.

This is a factual inventory, not a legal conclusion. The report explicitly keeps FFmpeg source correspondence and configure-line proof as release-owner review work because the resolved 0.18.1 AAR does not encode that information.

## Implementation

Native inventory script:

- Parses default coordinates:
  - `io.github.junkfood02.youtubedl-android:common:0.18.1`
  - `io.github.junkfood02.youtubedl-android:library:0.18.1`
  - `io.github.junkfood02.youtubedl-android:ffmpeg:0.18.1`
  - `com.github.teamnewpipe:NewPipeExtractor:v0.24.8`
  - `com.github.teamnewpipe.NewPipeExtractor:*:v0.24.8`
- Locates `.aar`, `.jar`, `.pom`, and `.module` files under Gradle's modules cache.
- Hashes every matched artifact with SHA-256.
- Inspects AAR/JAR/APK zip entries matching native, asset, raw-resource, license, yt-dlp, Python, QuickJS, FFmpeg, and FFprobe payload names.
- Opens nested `res/raw/ytdlp` and `*.zip.so` payloads where they are zip containers.
- Extracts yt-dlp version, git head, and origin from `yt_dlp/version.py`.
- Extracts Python payload versions from `usr/lib/pythonX.Y/` paths.
- Supports optional final APK inspection with `--apk`, used by release CI after the signed APK is packaged.
- Prints relative/home-relative paths instead of absolute workstation paths.

Release workflow:

- Runs `python3 tools/native_compliance_inventory.py --apk "${{ steps.package.outputs.apk_path }}" --output "$RELEASE_DIR/NATIVE-COMPLIANCE.md"`.
- Fails if `NATIVE-COMPLIANCE.md` is empty.
- Includes `NATIVE-COMPLIANCE.md` in `SHA256SUMS.txt`.
- Adds a release-note row for the native compliance packet.
- Uploads and tag-attaches `NATIVE-COMPLIANCE.md`.

## Source Evidence

- youtubedl-android 0.18.1 README documents `library` and `ffmpeg` Gradle dependencies, bundled yt-dlp/Python usage, FFmpeg initialization, GPL-3.0 licensing, and build-note links.
- youtubedl-android `BUILD_FFMPEG.md` and `BUILD_PYTHON.md` describe Termux-package build paths, but the current resolved AAR needs release-owner source correspondence review because the AAR itself does not encode the exact package source set.
- yt-dlp 2025.11.12 release notes identify the release and note zipimport release-file third-party licensing; the repository license is Unlicense.
- Python 3.12 documentation identifies the Python Software Foundation License Version 2 and incorporated-software license caveats.
- QuickJS upstream identifies MIT licensing.
- FFmpeg legal guidance says FFmpeg is LGPL 2.1-or-later by default, but GPL parts make GPL apply to all of FFmpeg when enabled, and its checklist requires matching source and build/configure evidence.
- NewPipeExtractor v0.24.8 is GPL-3.0-or-later and is the source for Aura's YouTube metadata extraction dependency.
