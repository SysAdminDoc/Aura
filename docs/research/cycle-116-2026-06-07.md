# Cycle 116 Research - Callable Rollout Evidence Receipt

## Goal

Prepare a checked, redacted receipt path for future live callable invocation
evidence without requiring owner credentials in the repository or release
artifacts.

## Local Evidence

- Cycle 115 made Android callable wire-protocol coverage machine-checkable for
  all seven contracted community write surfaces.
- Production callable enforcement still needs owner-approved deploy evidence,
  Firebase Console App Check evidence, live invocation evidence, and direct
  RTDB rule tightening.
- Existing account-deletion evidence tools validate private owner evidence and
  emit redacted receipts that omit raw project IDs, UIDs, paths, command
  output, credentials, and tokens.

## Implementation

- Added `docs/community-callable-rollout-evidence.md` to define private live
  callable evidence inputs, receipt command, acceptance criteria, redaction
  guarantees, and remaining production gates.
- Added `tools/community_callable_rollout_receipt.py` to validate
  owner-provided private live callable invocation evidence against
  `docs/community-callable-contract.json` and
  `docs/community-callable-wire-protocol.json`.
- The tool verifies manifest hashes, support reference, Functions App Check
  state, one invocation per contracted surface, function names, App Check token
  modes, response resource-ID fields, operation-ID prefixes, caller UID hashes,
  and per-invocation private evidence hashes.
- The redacted receipt hashes project ID, private evidence references,
  operation IDs, resource IDs, caller UID hashes, and per-invocation private
  evidence. It omits raw operation IDs, resource IDs, paths, project ID,
  command output, credentials, and tokens.
- Added `test/tools/community_callable_rollout_receipt_test.py` coverage for
  receipt redaction and drift failures for missing surfaces, token-mode drift,
  operation-prefix drift, manifest-hash drift, invalid App Check state, and
  duplicate receipt surfaces.
- Wired `.github/workflows/verify.yml` change detection for the new tool and
  rollout evidence runbook, and updated backend/callable runbooks.
