# Cycle 30 - FFmpeg Source Correspondence Evidence

Date: 2026-06-06

## Objective

Turn the unresolved FFmpeg source-correspondence risk into a concrete release
review record for the resolved `io.github.junkfood02.youtubedl-android:ffmpeg:0.18.1`
payload.

## Local Evidence

- `docs/legal/native-compliance.md` already recorded the resolved
  `ffmpeg-0.18.1.aar` SHA-256:
  `0a87ffa6cf912b0fe76c1a99b9107f543ee2f247935fae2c71f0822eb7bc5f49`.
- The native packet and overlay previously said FFmpeg build mode could not be
  inferred from the AAR.
- Local nested-payload inspection found each `libffmpeg.zip.so` contains FFmpeg
  shared libraries but no `usr/bin`, `usr/share`, Debian package control
  metadata, source files, or build logs.
- Embedded shared-library strings expose `FFmpeg version 7.1.1` and exact
  configure lines for `arm64-v8a`, `armeabi-v7a`, `x86`, and `x86_64`.
- The embedded configure lines include `--enable-gpl` and `--enable-version3`;
  none include `--enable-nonfree`.
