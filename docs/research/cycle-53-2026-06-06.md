# Cycle 53 - Firebase App Check Client Rollout

## Scope

Cycle 53 installs Firebase App Check in Aura's Android client and documents the
monitor-then-enforce rollout path for community writes. This is the client and
runbook slice only; Firebase console enforcement and per-write quotas remain
backend follow-up work.

## Primary Sources

- Firebase App Check overview: https://firebase.google.com/docs/app-check
- Firebase Android Play Integrity provider: https://firebase.google.com/docs/app-check/android/play-integrity-provider
- Firebase Android debug provider: https://firebase.google.com/docs/app-check/android/debug-provider
- Firebase App Check enforcement: https://firebase.google.com/docs/app-check/enable-enforcement

## Local Evidence

- `FreeVibeApp.warmCommunityIdentity()` touches Firebase Auth at startup when
  the Community source is enabled.
- Community writes flow through Firebase Auth, Realtime Database, and Storage
  repositories, but the app had no App Check provider installation.
- `app/build.gradle.kts` already used Firebase BoM 34.13.0 for Auth, Database,
  and Storage, so App Check libraries could stay version-aligned under the BoM.
- `docs/research/cycle-9-2026-06-04.md` had already identified App Check plus
  quotas as the staged abuse-control plan.

## Implementation

- Added App Check aliases to `gradle/libs.versions.toml`.
- Added `firebase-appcheck-playintegrity` to main dependencies and
  `firebase-appcheck-debug` to debug-only dependencies.
- Added variant-specific `AppCheckInstaller` implementations:
  - debug builds install `DebugAppCheckProviderFactory`;
  - release builds install `PlayIntegrityAppCheckProviderFactory`.
- Updated `FreeVibeApp.onCreate()` to install App Check before community
  identity warm-up or other Firebase-backed startup work.
- Added `docs/community-app-check-rollout.md` with debug-token registration,
  Play Integrity console setup, side-loaded distribution settings, metrics
  monitoring, enforcement gates, and remaining quota work.
- Refreshed Gradle dependency verification metadata and generated dependency
  notice locks for the new App Check and Play Integrity artifacts.
