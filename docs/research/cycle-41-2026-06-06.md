# Cycle 41 Research: Bing Daily Source Switch

## Goal

Close the remaining missing runtime-control row for Bing Image of the Day so
Discover and wallpaper rotations can skip Bing deliberately when a build or user
profile disables that provider.

## Local Evidence

- `WallpaperRepository.getDiscover()` used Bing as its only secondary Discover
  source through `getBingDaily()`.
- `AutoWallpaperWorker.fetchWallpapers()` supported `"bing"` as both legacy
  auto-wallpaper and scheduler rotation source.
- Settings source pickers always offered Bing Daily, even though previous cycles
  already hid disabled Pixabay rotation choices.
- `ProviderDisclosure.kt` and `docs/legal/provider-runtime-controls.md` marked
  Bing as `Missing` because it had no first-class disabled state.

## Decision

Add a default-on `bing_provider_enabled` preference instead of a remote profile
stub. This matches the existing YouTube, Reddit, Pexels, Pixabay, and Community
control pattern and gives users and future distribution profiles the same
runtime switch surface.

## Implementation Notes

- `PreferencesManager` now stores `bing_provider_enabled` and exposes a setter.
- Settings now shows an `Enable Bing Daily source` switch and hides Bing from
  auto-wallpaper source pickers when disabled, while preserving stale selected
  values so users can see and change them.
- `WallpaperRepository.getBingDaily()` returns an empty source result and
  records disabled diagnostics before cache fallback or Retrofit calls when the
  flag is off.
- `AutoWallpaperWorker` exits successfully for disabled scheduled or legacy
  Bing rotations after invoking the repository guard, avoiding retry loops.
- Runtime-control docs now mark Bing as covered.

## Verification Plan

- Focused repository test proves disabled Bing records a disabled diagnostic and
  never calls the Bing API.
- Focused Settings test ensures the new Settings flow is wired.
- Provider disclosure test verifies Bing is no longer a missing runtime-control
  row.
- Release-compliance Python checks remain unchanged and should still pass.
