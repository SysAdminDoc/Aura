# Cycle 149 research - SBOM readiness gate

## Question

Owner-gated production evidence is still unavailable, so this pass focused on
release artifact hardening. The open question was whether Aura should generate
CycloneDX/SPDX SBOM artifacts immediately or keep SBOM generation deferred until
the N-1 AGP/Gradle/Kotlin/KSP toolchain upgrade.

## Sources

- CycloneDX Gradle plugin: https://github.com/CycloneDX/cyclonedx-gradle-plugin
- CycloneDX tool center: https://cyclonedx.org/tool-center/
- GitHub artifact attestations: https://docs.github.com/en/actions/concepts/security/artifact-attestations
- GitHub provenance and SBOM attestations: https://docs.github.com/actions/security-guides/using-artifact-attestations-to-establish-provenance-for-builds
- SPDX overview: https://spdx.dev/about/overview/

## Findings

- CycloneDX has a maintained Gradle plugin that can become Aura's future
  Android dependency graph SBOM lane, but adding another Gradle plugin before
  the already-planned N-1 migration creates avoidable toolchain churn.
- SPDX remains a credible SBOM publication format, so the future contract
  should not hard-code CycloneDX as the only acceptable output.
- GitHub artifact attestations already protect Aura's release checksum file.
  If Aura later publishes an SBOM artifact, the release workflow should include
  that file in checksums, release notes, tagged release assets, and any
  supported attestation evidence.
- Aura's current release evidence floor is already stronger than a plain APK
  attachment: generated notices, raw Google OSS inputs, dependency notice lock,
  curated high-risk license policy, native compliance lock, native compliance
  packet, checksums, release bundle validation, and artifact attestation.

- Added the release workflow snippet to
  `docs/distribution/github-security-workflows.json`.
- Added the new command and README link to the release metadata consistency
  packet.
- Updated release dry-run, release signing, supply-chain, README, roadmap,
  changelog, completion, and loop-state docs.

## Decision

Keep SBOM generation deferred until N-1, but make the deferral checked. The
future artifact names are:

- `SBOM.cyclonedx.json`
- `SBOM.cyclonedx.xml`
- `SBOM.spdx.json`

The future scope is:

- Gradle plugins and version-catalog dependencies.
- Release runtime dependency graph.
- Native, FFmpeg, and youtubedl-android payloads.
- Release APK digest and signing certificate fingerprint.
