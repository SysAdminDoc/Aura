# Cycle 92 - Hosted Deletion Page Template Gate

## Scope

Add a checked hosted account deletion page template so the owner can publish a
valid HTTPS deletion request page without inventing copy at submission time.

## Sources

- Google Play account deletion requirements:
  https://support.google.com/googleplay/android-developer/answer/13327111
- Google Play User Data policy:
  https://support.google.com/googleplay/android-developer/answer/10144311
- Existing web-intake contract:
  `docs/support/community-account-deletion-web-intake.md`

## Local Evidence

- Cycle 88 added the pending/published URL manifest, but the repo still lacked
  a checked public page body for the owner to publish.
- The page must let users request deletion without going back to the app, must
  reference Aura, must collect the same private support fields as the intake
  validator, and must disclose retained records plus separate public-upload
  handling.
- Public copy should not request sensitive identifiers or secrets.

## Implementation

- Added `docs/support/community-account-deletion-web-page.md` with publishable
  hosted page copy, required form fields, retained-record disclosure, public
  upload caveat, and privacy-policy link requirement.
- Added `tools/community_deletion_web_page_check.py` to validate required page
  terms, required web-intake field names, app-independent request copy, and
  forbidden sensitive identifier/secret requests.
- Added `test/tools/community_deletion_web_page_check_test.py` for the valid
  template plus missing field, sensitive identifier, and app-dependent request
  path failures.
- Wired the page validator into Firebase backend CI change detection.
- Updated privacy, policy, support, backend runbook, roadmap, changelog,
  completed ledger, and loop state docs.
