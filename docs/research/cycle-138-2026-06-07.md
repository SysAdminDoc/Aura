# Cycle 138 - Store Metadata Preflight

## Scope

Cycle 138 implemented the checkable text/version/privacy portion of the store
listing metadata preflight. Owner-gated live callable evidence, hosted deletion
URL publication, production Firebase dry runs, GitHub security settings
evidence, signed release dry-run evidence, and fresh screenshot capture remained
unavailable locally.

## Current Finding

Aura already had a Fastlane metadata tree, but the short description was 81
characters after trimming. Google Play's short-description limit is 80
characters. The tree also had no automated check tying the current Gradle
`versionCode` to a Fastlane changelog and no checked public privacy-policy URL
in the full description.

The repo still has only one root screenshot artifact and no committed Fastlane
feature graphic. Those assets need real visual capture/review, so Cycle 138
implemented and tested the asset-check mode without enabling it in CI yet.

## Implementation

- Added `tools/store_metadata_preflight.py`.
- Checked title length, short description length and single-line formatting,
  full description length, stale `FreeVibe` branding, public privacy-policy URL,
  no-ads/no-tracking copy, privacy-policy coverage, current versionCode
  changelog presence, and current versionName mention.
- Added an optional `--require-assets` mode for Fastlane `images/icon.png`,
  `images/featureGraphic.*`, and `images/phoneScreenshots/*` dimensions and
  no-alpha requirements.
- Wired text-mode preflight into `verify.yml` and `release.yml`.
- Updated the release workflow security policy so the release preflight cannot
  silently lose this guard.
- Shortened the Fastlane short description and added the public privacy-policy
  URL to the full description.

## Verification

- `py -3 tools\store_metadata_preflight.py --repo-root .`
- `py -3 -m unittest discover -s test/tools -p '*_test.py'`
- Planned policy checks for the updated workflows:
  `tools/github_security_workflow_check.py`,
  `tools/github_actions_allowlist_check.py`,
  `tools/github_workflow_permissions_check.py`, and
  `tools/github_workflow_secrets_check.py`.

## Remaining Work

- Enable `tools/store_metadata_preflight.py --require-assets` after the
  screenshot and feature-graphic pipeline lands.
- Add alt-text notes for the final graphics before store submission.
