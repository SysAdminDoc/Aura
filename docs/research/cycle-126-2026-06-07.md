# Cycle 126 Research - Diagnostics Redaction Fixture Suite

## Goal

Prove the local crash diagnostics bundle redacts real Aura provider credential
shapes before users copy support bundles into public issues.

## Local Evidence

- `CrashDiagnosticsCollector.kt` builds a local-only diagnostics bundle and
  passes the crash-log tail through `CrashDiagnosticsText.sanitize()`.
- `CrashDiagnosticsTextTest` already covered broad bearer, `apiKey`, query
  token, app-private path, and `file://` redaction.
- `local.properties.example` documents provider properties named
  `pexels.api.key`, `pixabay.api.key`, `freesound.api.key`,
  `soundcloud.client.id`, and `stability.ai.key`.
- `docs/research/cycle-15-2026-06-04.md` called out missing fixtures for
  `?apikey=`, `?key=`, `?token=`, `?client_id=`,
  `Authorization: Bearer`, assignment-style `apiKey`,
  `stability.ai.key`, `local.properties`, `file://`, and app-private paths.

## Implementation

- Extended `CrashDiagnosticsText.sanitize()` so assignment redaction covers
  dotted provider credential names such as `stability.ai.key` and
  `soundcloud.client.id`, while preserving the key name and replacing only the
  value with `<redacted>`.
- Added a provider-specific synthetic crash fixture that includes Wallhaven,
  Pixabay, Freesound, SoundCloud, Pexels, Settings, `local.properties`,
  `file://`, and app-private path examples.
- The fixture asserts every raw sentinel value is absent while source/provider
  context and `local.properties` context remain present.
- Updated support docs and the crash-report issue template to describe the
  provider query/header, local provider-property, app-private path, and file URI
  redaction coverage.

## Verification

```powershell
.\gradlew.bat --no-daemon --max-workers=2 ":app:testDebugUnitTest" --tests "com.freevibe.service.CrashDiagnosticsTextTest" --stacktrace
```

Result: passed. The expanded fixture initially caught the missing dotted
provider-property assignment redaction, then passed after the sanitizer grammar
was tightened.

## Remaining Risk

- This pass does not add a shared URL/request redactor for source metrics or
  provider repositories. That remains tracked by the separate redacted URL and
  request logging contract item.
- This pass does not change provider key storage. The storage classification
  and Keystore decision item remains open.
