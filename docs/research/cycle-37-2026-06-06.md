# Cycle 37 - YouTube Provider Legal-Mode Switch

Date: 2026-06-06

## Research

YouTube remains Aura's highest-risk active provider because it is not only a
catalog source. The current feature set can search YouTube, import pasted watch
URLs, pre-resolve preview audio, download/apply audio, list video wallpapers, and
download video wallpaper media through extractor/downloader paths. YouTube API
Services policies restrict downloading, importing, backing up, caching, storing,
and offline playback outside allowed API behavior, so a release-oriented
legal-mode switch must block resolver and cache paths, not just hide a tab.

## Local Evidence

- `YouTubeRepository.kt` owned NewPipe search plus yt-dlp audio/video stream
  resolution and an in-memory stream URL cache.
- `SoundsViewModel.kt` used YouTube for the first-run sound feed, the explicit
  YouTube tab, search mode, pasted URL imports, similar sounds, top hits, preview
  prebuffering, and download/apply resolution.
- `VideoWallpapersViewModel.kt` attempted YouTube discovery alongside Pexels,
  Reddit, and Pixabay, pre-resolved YouTube stream URLs, and used yt-dlp for
  YouTube video wallpaper downloads.
- `SourceMetrics.kt` counted provider failures but had no separate disabled
  state for intentional provider-off behavior.

## Decision

Add a default-on `youtube_provider_enabled` preference so current installs keep
their existing behavior, then gate all YouTube entry points behind that flag.
Disabled mode should leave useful bundled sound content on first run, hide
YouTube browsing affordances, skip YouTube video discovery, and report disabled
source decisions separately from provider outages.

## Implementation

- Added `PreferencesManager.youtubeProviderEnabled` and a Settings switch for
  YouTube features.
- Added disabled-source counters to `SourceMetrics` and surfaced disabled counts
  in Settings diagnostics and crash context.
- Gated `YouTubeRepository` before search, cached preview lookup, audio stream
  resolution, and video stream resolution.
- Updated Sounds to fall back to bundled ringtone/notification/alarm content,
  hide the YouTube secondary tab, block YouTube search/import/playback/download,
  and skip similar-sound/top-hit YouTube calls when disabled.
- Updated Video Wallpapers to skip YouTube catalog jobs, pre-resolve work, and
  apply/download paths when the flag is disabled.
- Updated the runtime provider-control matrix to mark YouTube covered by the
  legal-mode switch while keeping channel-specific distribution defaults open.

## Verification Plan

- Run focused JVM tests for Sounds behavior, sound-tab helpers, source metrics,
  and provider runtime controls.
- Run release-compliance Python checks to keep existing legal artifact gates
  green.
- Run `git diff --check` and the changed-line attribution scan before commit.
