# Cycle 73 - Report/Profile Block Actions

## Scope

Close the remaining visible block-user entry points that can resolve canonical
community uploader IDs: creator profile rows and admin report cards. Keep the
block action as a private user preference, not a moderation action.

## Sources

- Google Play User Generated Content policy:
  https://support.google.com/googleplay/android-developer/answer/9876937
- Google Play moderation requirements:
  https://support.google.com/googleplay/android-developer/answer/12923286
- Firebase Realtime Database Android read/write documentation:
  https://firebase.google.com/docs/database/android/read-and-write
- Firebase Realtime Database Security Rules:
  https://firebase.google.com/docs/database/security

## Local Evidence

- `CommunityReportInput` previously carried source, license, and uploader
  display text, but not a canonical uploader UID. Report cards therefore could
  not safely target the private block list.
- Community sound and wallpaper UI models already expose
  `communityUploaderId`, populated from canonical `uploaderUid` or legacy
  `uploaderId` metadata.
- `CreatorProfileDashboard` rows already use canonical creator IDs and were
  already filtered by private block state on reload.

## Implementation

- Added optional `uploaderUid` metadata to report inputs, stored report records,
  sound report submissions, and wallpaper report submissions.
- Added a Realtime Database rule validator for optional report `uploaderUid`
  values and emulator coverage for the accepted field plus the length guard.
- Added admin report-card `Block creator` actions when reports carry community
  uploader UID metadata. The action writes through `CommunityBlockRepository`.
- Added creator-profile `Block creator` actions for non-current-user creators.
  Successful blocks immediately remove matching top-creator, followed-creator,
  and followed-upload rows using the same normalized owner-key matching as feed
  filtering.
- Updated the community block-user policy, roadmap, changelog, completed
  ledger, and loop state.
