# Cycle 141 - Manifest Permission Data Safety Gate

## Scope

Cycle 141 added the first enforceable Data safety matrix slice: every manifest
permission now has a reviewed privacy/store row and release preflight guard.
Owner-gated live callable evidence, hosted deletion URL publication,
production Firebase dry runs, GitHub security settings evidence, signed release
dry-run evidence, and fresh store screenshots remained unavailable locally.

## Current Finding

Aura declares permissions for wallpapers, sound apply flows, microphone
recording, networking, legacy storage, boot/scheduling, foreground services,
notifications, weather location, and per-contact ringtones. Google Play's Data
safety and sensitive-permission policies require accurate disclosure for data
access, collection, sharing, and sensitive permissions. Before this cycle,
there was no checked manifest-to-privacy ledger.

## Implementation

- Added `docs/privacy/data-safety.md` with a release-reviewed permission ledger
  and Data safety answer notes.
- Added `docs/privacy/data-safety.json` with one structured row for each
  manifest permission.
- Added `tools/privacy_data_safety_check.py` to parse
  `app/src/main/AndroidManifest.xml`, require an exact permission-row match,
  verify `maxSdkVersion` values, require purpose/data type/collection/sharing/
  retention/deletion/denial/Play declaration fields, and ensure the Markdown
  matrix lists every permission.
- Added focused backend tests for the live matrix, missing rows, extra rows,
  maxSdk drift, missing fields, missing docs rows, and non-HTTPS source URLs.
- Wired the check into verify and release workflows before Android setup or
  signed APK assembly.
- Updated release workflow security policy, release signing docs, release
  dry-run docs, supply-chain docs, privacy policy, roadmap, changelog,
  completion, and loop-state docs.

## Verification

- `py -3 tools\privacy_data_safety_check.py --policy docs\privacy\data-safety.json --repo-root .`
- `py -3 -m unittest discover -s test/tools -p '*_test.py'`
