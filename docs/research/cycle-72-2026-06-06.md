# Cycle 72 - Blocked Creators Review

## Scope

Cycle 72 adds the first blocked-users review and unblock surface. Settings now
shows the current private block list as blocked creators and lets the signed-in
user remove individual blocks.

## Primary Sources

- Google Play User Generated Content policy:
  https://support.google.com/googleplay/android-developer/answer/9876937
- Google Play moderation requirements for UGC apps:
  https://support.google.com/googleplay/android-developer/answer/12923286
- Firebase Realtime Database Android read/write documentation:
  https://firebase.google.com/docs/database/android/read-and-write
- Firebase Realtime Database Security Rules:
  https://firebase.google.com/docs/database/security

## Local Evidence

- Cycle 70 added block-list reads/writes and unblock writes in
  `CommunityBlockRepository`.
- Cycle 71 added detail-screen block actions, but users still had no UI to
  review or undo their private block list.
- Settings already owns community source controls, creator profile navigation,
  and admin report navigation, so it is the smallest existing surface for a
  private community safety control.

## Implementation

- Added `CommunityBlockedUser` records with `userId`, `reason`, and `createdAt`
  metadata.
- Added `CommunityBlockRepository.blockedUsers()` and snapshot parsing for
  sorted blocked-user rows.
- Added `SettingsViewModel.blockedCommunityCreators` plus
  `unblockCommunityCreator()` action state.
- Added a Settings `Blocked creators` row under Community controls with a
  count-aware subtitle.
- Added a `BlockedCreatorsDialog` listing blocked uploader IDs, reason/timestamp
  metadata, and per-row unblock actions with in-row progress.
