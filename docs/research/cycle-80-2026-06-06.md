# Cycle 80 - Account Deletion Executor Package

## Scope

Add the private package step a future trusted account deletion executor can use
after lookup, plan, review, and simulation all pass.

## Sources

- Google Play account deletion requirements:
  https://support.google.com/googleplay/android-developer/answer/13327111
- Firebase Realtime Database delete data:
  https://firebase.google.com/docs/database/android/read-and-write#delete_data
- Cycle 79 apply simulator:
  `tools/community_account_deletion_apply_simulator.py`
- Cycle 78 review gate:
  `tools/community_account_deletion_review.py`

## Local Evidence

- The simulator proves the reviewed update set against a local export, but a
  future executor still needs one private package with the exact multi-path
  RTDB null updates and the hashes that prove provenance.
- The package must not contact Firebase or imply self-service deletion is
  complete.
- Because the package contains full RTDB update paths, it must be private
  operator evidence and never a public support artifact.

## Implementation

- Added `tools/community_account_deletion_executor_package.py`.
- The package builder validates the review receipt, simulation receipt,
  request code, operator label, plan hash, review hash, simulation hash,
  retained roots, and zero remaining update paths.
- The output contains `packageStatus=readyForTrustedExecutor`, full RTDB
  null-update payload, hashes, redacted UID suffix, snapshot hash, operator, and
  a private-package warning.
- Added `test/tools/community_account_deletion_executor_package_test.py`.
- Wired the package builder into Firebase backend CI change detection.
- Updated support, policy, runbook, roadmap, changelog, completed ledger, and
  loop state docs.
