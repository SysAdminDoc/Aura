# Cycle 28 - Raw Release Notice Input Preservation

Date: 2026-06-06

## Objective

Preserve the raw Google OSS Licenses inputs that produce `THIRD-PARTY-NOTICES.md` and `docs/legal/dependency-notices.lock.json`, so future dependency drift reviews can inspect the original generated files without rerunning Gradle.

## Local Evidence

Cycle 22 and Cycle 24 established the raw Google output paths:

- `app/build/generated/third_party_licenses/release/dependencies.json`
- `app/build/generated/res/releaseOssLicensesTask/raw/third_party_license_metadata`
- `app/build/generated/res/releaseOssLicensesTask/raw/third_party_licenses`

Those files feed:

- `tools/google_oss_to_markdown.py`
- `tools/dependency_notice_lock.py`
- `docs/legal/dependency-notices.lock.json`

The release workflow already generates them through `:app:releaseOssLicensesTask`, but only the markdown notice artifact was preserved after the run.

## Implementation

Added `tools/google_oss_raw_archive.py`.

The archive tool:

- Requires all three raw Google OSS inputs to exist and be non-empty.
- Writes `GOOGLE-OSS-RAW-INPUTS.zip`.
- Stores deterministic zip entries with fixed timestamps and file modes.
- Includes `MANIFEST.json` with schema version, variant, source paths, file sizes, and SHA-256 digests.
- Prints JSON with archive path, size, SHA-256, variant, and manifest file records.

Updated `.github/workflows/release.yml` to:

- Run the raw archive tool after `THIRD-PARTY-NOTICES.md` generation.
- Include `GOOGLE-OSS-RAW-INPUTS.zip` in `SHA256SUMS.txt`.
- Mention the archive in release notes.
- Upload the archive in workflow artifacts.
- Attach the archive to tagged GitHub Releases.

Updated `tools/release_artifact_bundle_check.py` to require the archive in:

- Required release files.
- `SHA256SUMS.txt`.
- Release notes.

Updated:

- `docs/distribution/release-dry-run.md`
- `docs/distribution/release-signing.md`
- `docs/distribution/supply-chain.md`
- `ROADMAP.md`
- `COMPLETED.md`
- `CHANGELOG.md`
- `AUTONOMOUS-LOOP-STATE.md`

## Result

Cycle 28 preserves the raw Google OSS notice inputs beside the human-readable notice packet. Release reviewers now get:

- `THIRD-PARTY-NOTICES.md` for readable review.
- `GOOGLE-OSS-RAW-INPUTS.zip` for raw generated evidence.
- `docs/legal/dependency-notices.lock.json` for deterministic drift detection.
