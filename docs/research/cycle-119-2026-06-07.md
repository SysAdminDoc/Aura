# Cycle 119 Research - GitHub Security Settings Receipt

## Goal

Prepare a checked, redacted receipt path for future owner-provided live GitHub
repository security settings evidence without committing raw screenshots,
API responses, private paths, credentials, or tokens.

## Local Evidence

- Cycle 117 added a checked policy guard for Dependency Review, OpenSSF
  Scorecard, and Release workflows.
- Cycle 118 added checked Dependabot version-update coverage for GitHub
  Actions, Gradle, root npm, and Functions npm.
- Live branch protection, required checks, Dependabot alerts/security updates,
  code scanning, secret scanning, and release-attestation visibility still
  require owner/admin access in GitHub.

## Implementation

- Added `docs/distribution/github-security-settings-evidence.md` to define the
  private evidence schema, receipt command, acceptance criteria, redaction
  guarantees, and remaining live GitHub gates.
- Added `tools/github_security_settings_receipt.py` to validate private
  owner-provided GitHub settings evidence against
  `docs/distribution/github-security-workflows.json` and `.github/dependabot.yml`.
- The tool verifies the workflow policy hash, Dependabot config hash, branch
  protection for `main`, verify and Firebase rules required checks,
  up-to-date branch requirement, force-push and deletion blocks, Dependabot
  version updates, Dependabot alerts/security updates, Scorecard SARIF code
  scanning, secret scanning, and release-attestation evidence hashes.
- The redacted receipt hashes repository name, required-check names, private
  evidence references, release-attestation evidence references, and raw private
  evidence. It omits raw repository names, private evidence paths, raw
  required-check names, screenshots, API responses, credentials, and tokens.
- Added `test/tools/github_security_settings_receipt_test.py` coverage for
  receipt redaction and drift failures around missing required checks, policy
  hash drift, disabled Dependabot alerts, disabled secret scanning, and
  support-reference drift.
- Updated `docs/distribution/supply-chain.md`, `ROADMAP.md`, `COMPLETED.md`,
  `CHANGELOG.md`, and loop state with the new receipt gate.

## Remaining Risk

- This cycle provides the receipt validator only; no private owner/admin GitHub
  settings evidence was present in the repo.
- Live repository security claims still require owner/admin evidence from
  GitHub for branch protection, required checks, Dependabot alerts/security
  updates, code scanning, secret scanning, and release-attestation visibility.

  deploy evidence, Firebase Console App Check evidence, valid private live
