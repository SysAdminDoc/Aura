# Cycle 147 - Alternative-store Disclosure Gate

## Scope

Cycle 147 started after the Community Guidelines consent gate landed. Owner
access for live callable evidence, hosted deletion URL publication, production
Firebase dry runs, GitHub security settings evidence, signed release dry-run
evidence, and fresh screenshots remained unavailable locally. This pass
completed the next checkable distribution item: alternative-store anti-feature,
permission, network-service, and dependency disclosure.

## Research Finding

F-Droid metadata and IzzyOnDroid metadata both need clear store-facing
disclosure for dependencies, network services, anti-feature labels, sensitive
permissions, graphics/screenshots, and upstream APK provenance. Aura remains a
full-build GitHub/Obtainium app with IzzyOnDroid as the realistic near-term
store candidate, while F-Droid mainline remains blocked by Firebase, Google
Services, and Play Services ML Kit dependencies.

## Local Evidence

- `docs/distribution/channel-strategy.md` records the full-build decision and
  F-Droid unblock criteria.
- `tools/fdroid_preflight.py --expect-blocked --json` still reports blocked
  status from the Google Services plugin, Firebase dependencies, Play Services
  ML Kit, and missing product flavors.
- `docs/privacy/data-safety.json` contains all 15 manifest permission rows.
- `docs/security/network-endpoints.json` contains all 15 reviewed network
  endpoint IDs.
- Public release docs already require signed APKs, checksums, release notes,
  and artifact attestation for GitHub/Obtainium users.

## Implementation

- Added `docs/distribution/alt-store-metadata.md` as the owner-facing
  disclosure packet for GitHub, Obtainium, IzzyOnDroid, and F-Droid mainline.
- Added `docs/distribution/alt-store-metadata.json` as the checked machine
  contract for channel status, anti-feature notes, proprietary dependency
  markers, manifest permission disclosures, reviewed network-service rows,
  Izzy submission notes, and source URLs.
- Added `tools/alt_store_metadata_check.py` to validate package identity,
  required docs sections, source URLs, channel statuses, anti-feature labels,
  marker files, manifest permissions, endpoint IDs, and Izzy notes.
- Added focused backend tests for the live packet, missing permission rows,
  missing network-service rows, missing proprietary dependency markers, and
  stale F-Droid mainline readiness claims.
- Wired the gate into verify and release workflows before Android build work.
- Updated release dry-run, release signing, supply-chain, channel strategy, and
  README links for the new disclosure packet.
