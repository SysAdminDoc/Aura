## Real Repo Implementation

Gradle wiring:

- `settings.gradle.kts`
  - Added `pluginManagement.resolutionStrategy` mapping:
    - plugin id `com.google.android.gms.oss-licenses-plugin`
    - module `com.google.android.gms:oss-licenses-plugin:${requested.version}`
- `build.gradle.kts`
  - Added `id("com.google.android.gms.oss-licenses-plugin") version "0.12.0" apply false`
- `app/build.gradle.kts`
  - Applied `id("com.google.android.gms.oss-licenses-plugin")`
  - Did not add `implementation("com.google.android.gms:play-services-oss-licenses:17.5.1")`

Verification metadata:

- `gradle/verification-metadata.xml`
  - Added `com.google.android.gms:oss-licenses-plugin:0.12.0`
  - Added plugin-classpath protobuf 4.34.1 artifacts:
    - `com.google.protobuf:protobuf-bom:4.34.1`
    - `com.google.protobuf:protobuf-java:4.34.1`
    - `com.google.protobuf:protobuf-parent:4.34.1`

Converter:

- `tools/google_oss_to_markdown.py`
  - Reads `dependencies.json`, `third_party_license_metadata`, and `third_party_licenses`.
  - Writes deterministic markdown with input paths, dependency coordinate table, and extracted license text sections.
  - Defaults to `release/THIRD-PARTY-NOTICES.md` for release workflow use.

Release workflow:

- `.github/workflows/release.yml`
  - Runs `./gradlew :app:releaseOssLicensesTask --stacktrace --no-daemon`.
  - Runs `python3 tools/google_oss_to_markdown.py --variant release --output "$RELEASE_DIR/THIRD-PARTY-NOTICES.md"`.
  - Adds `THIRD-PARTY-NOTICES.md` to `SHA256SUMS.txt`.
  - Adds the notices file to uploaded workflow artifacts and tagged release attachments.
  - Adds a release-note line for third-party notices.

Supply-chain docs:

- `docs/distribution/supply-chain.md`
  - Adds third-party notices to active controls.
  - Updates release verification steps to require notice artifact and checksum coverage.
  - Documents local generation commands.
  - Records that generated dependency notices do not replace `ProviderDisclosure.kt` content-source disclosures.

