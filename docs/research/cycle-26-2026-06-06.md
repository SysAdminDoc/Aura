# Cycle 26 - Curated High-Risk Dependency Overlay

Date: 2026-06-06

## Objective

Close the review gap left by generated Google OSS notices, dependency notice locks, and native compliance locks. Those files prove what changed, but they do not preserve curated source URLs, license IDs, app usage notes, or release-owner review notes for Aura's highest-risk dependency and payload families.

## Local Evidence

- `docs/legal/dependency-notices.lock.json` records 251 release dependency coordinates and 288 generated notice sections.
- `docs/legal/native-compliance.lock.json` records 8 native/copyleft coordinates, 23 artifact records, and 36 payload entries.
- `docs/legal/native-compliance.md` identifies youtubedl-android, NewPipeExtractor, yt-dlp, Python, QuickJS, and FFmpeg payload evidence.
- `.github/workflows/verify.yml` and `.github/workflows/release.yml` already run the dependency notice lock and native compliance lock gates after `:app:releaseOssLicensesTask`.
- The generated Google OSS outputs do not provide one reviewed source URL, license ID, usage description, and release-review note per high-risk dependency family.

## Implementation

Added `docs/legal/dependency-notice-overrides.json` with required curated entries for:

- `firebase-android-sdk`
- `ffmpeg-payload`
- `google-mlkit-subject-segmentation`
- `google-play-services`
- `newpipe-extractor`
- `profileinstaller`
- `python-runtime`
- `quickjs-runtime`
- `youtubedl-android`
- `yt-dlp-payload`
- `zxing-core`

Added `tools/dependency_overlay_check.py` to validate the overlay against current generated evidence:

- Required entry IDs must be present.
- Required fields: `id`, `licenseId`, `reviewNote`, `sourceUrl`, `target`, `targetType`, `usage`.
- `sourceUrl` must use HTTPS.
- `targetType=coordinate` must match a dependency/native coordinate exactly.
- `targetType=coordinate-prefix` must match at least one dependency/native coordinate prefix.
- `targetType=group` must match at least one dependency/native group ID.
- `targetType=payload` must match payload targets inferred from the native compliance lock (`yt-dlp`, `python-runtime`, `quickjs`, `ffmpeg`).
- Unsupported target types, duplicate IDs, missing required fields, missing required entries, and stale/orphaned targets fail validation.

Wired the check into:

- `.github/workflows/verify.yml`
- `.github/workflows/release.yml`
- `docs/distribution/supply-chain.md`

## Result

Cycle 26 shipped the curated high-risk dependency overlay and made it part of both PR/main verification and release packaging. Dependency or payload drift now has three layers of review evidence:

- Generated notice drift gate.
- Native/copyleft artifact and payload drift gate.
- Curated source/license/usage/review overlay gate.
