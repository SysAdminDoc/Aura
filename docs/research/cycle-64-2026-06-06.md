# Cycle 64 - Community Backend Deploy and Rollback Evidence

## Scope

Cycle 64 adds deploy/rollback dry-run evidence for the Firebase community
backend. The goal is to make Realtime Database and Cloud Storage rules changes
auditable before an operator runs a production deploy.

## Primary Sources

- Firebase CLI reference:
  https://firebase.google.com/docs/cli
- Firebase App Check overview:
  https://firebase.google.com/docs/app-check
- App Check enforcement:
  https://firebase.google.com/docs/app-check/enable-enforcement
- Cloud Storage lifecycle management:
  https://docs.cloud.google.com/storage/docs/lifecycle

## Local Evidence

- `firebase.json` maps `database.rules.json` and `storage.rules` into one
  deployable Firebase backend surface.
- `package.json` pins `firebase-tools` 15.19.1 and exposes the combined
  `test:firebase-rules` Emulator Suite command.
- `npx firebase deploy --help` on the pinned CLI shows `--dry-run` support for
  deployment validation without applying changes, with the caveat that
  validation can still enable APIs on the target project.
- `docs/firebase-admin-claims.md` previously documented direct deploy commands
  but did not record a complete evidence packet or rollback sequence.

## Implementation

- Added `tools/community_backend_manifest.py` with deterministic write/check
  modes for Firebase backend file hashes, deploy targets, pinned CLI version,
  rules-test scripts, and operator command templates.
- Added `docs/community-backend-manifest.json` for the current deployable
  backend state.
- Added a `Community backend manifest` step to the path-gated
  `.github/workflows/verify.yml` Firebase rules job.
- Added `docs/community-backend-runbook.md` covering required preflight,
  production-project dry run, deploy command, rollback command, App Check
  rollback separation, and release checklist evidence.
- Updated `docs/firebase-rules-harness.md`, `docs/firebase-admin-claims.md`, and
  `docs/community-app-check-rollout.md` to point at the manifest and runbook.

## Verification

```powershell
py -3 -m py_compile tools\community_backend_manifest.py
py -3 tools\community_backend_manifest.py --mode check
npx firebase deploy --help
```
