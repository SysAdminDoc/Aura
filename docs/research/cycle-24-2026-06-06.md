## Executive Summary

Cycle 24 adds the release-runtime dependency notice drift gate that remained open after the generated notices and native packet work.

Implemented in the real repo:

- `tools/dependency_notice_lock.py` writes and checks a deterministic lockfile generated from Google OSS release outputs.
- `docs/legal/dependency-notices.lock.json` records 251 sorted release dependency coordinates, 288 notice section hashes, and SHA-256 hashes for the generated Google input files.
- `.github/workflows/verify.yml` runs `:app:releaseOssLicensesTask` and checks the lockfile on PRs, main pushes, and manual verification.
- `.github/workflows/release.yml` checks the same lockfile before producing `THIRD-PARTY-NOTICES.md`.
- `docs/distribution/supply-chain.md` documents intentional regeneration and review.

The gate is intentionally based on the Google-generated release output already adopted in Cycle 22. It catches dependency/version additions, removals, generated input hash changes, and notice text/metadata changes. It does not claim per-coordinate source URLs or license IDs because Google's `dependencies.json` output only carries group/name/version identity.

## Implementation

Lock tool:

- Reads `app/build/generated/third_party_licenses/release/dependencies.json`.
- Reads `app/build/generated/res/releaseOssLicensesTask/raw/third_party_license_metadata`.
- Reads `app/build/generated/res/releaseOssLicensesTask/raw/third_party_licenses`.
- Sorts dependency coordinates deterministically.
- Hashes the dependency JSON, metadata file, full license text file, and every notice section.
- Writes `docs/legal/dependency-notices.lock.json` with schema version, variant, input paths, input hashes, counts, dependencies, and notice sections.
- In check mode, compares the current generated output to the committed lockfile and prints added/removed dependency or notice-section summaries before exiting nonzero.

Workflow integration:

- `verify.yml`
  - Runs `./gradlew :app:releaseOssLicensesTask --stacktrace --no-daemon`.
  - Runs `python3 tools/dependency_notice_lock.py --mode check --lockfile docs/legal/dependency-notices.lock.json`.
- `release.yml`
  - Runs the same lockfile check after `:app:releaseOssLicensesTask` and before `THIRD-PARTY-NOTICES.md` conversion.
