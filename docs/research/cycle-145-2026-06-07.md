# Cycle 145 - Play App Content Packet Gate

## Scope

Cycle 145 started after the SDK Data safety gate landed. Owner-gated live
callable evidence, hosted deletion URL publication, production Firebase dry
runs, GitHub security settings evidence, signed release dry-run evidence, and
fresh store screenshots remained unavailable locally, so this pass addressed
the next checkable Play policy artifact: an owner-ready App content declaration
packet.

## Policy Finding

Google Play's App content page is where developers provide privacy policy, ads,
app access, target audience, content rating, Data safety, and sensitive
permission information before review. The Data safety guidance also says third
party SDK collection/sharing must be reflected in the form. UGC guidance
requires report/block functionality and timely moderation, and the generated
content guidance covers text-to-image generation and in-app report/flag flows.

Aura has most of the required evidence in source and docs, but Play production
submission still needs owner actions for the hosted HTTPS account deletion URL,
Play Console live content rating answers, App content receipt capture, and UGC
terms/guidelines consent before users engage with community content.

## Local Evidence

- `docs/privacy/data-safety.json` now covers manifest permissions, network
  endpoints, local storage surfaces, and SDK surfaces.
- `docs/privacy/privacy-policy.md` and Fastlane metadata both state no ads and
  no tracking/cross-app tracking.
- `docs/support/community-reporting.md`,
  `docs/community-block-user-policy.md`, and
  `docs/community-upload-deletion.md` document report, block, moderation,
  takedown, and delete controls for community UGC.
- `docs/privacy/ai-generation.md` documents generated wallpaper disclosure,
  provider data, local storage, and generated-content report controls.
- `docs/support/community-account-deletion-web-url.json` still records the
  hosted deletion URL as pending owner publication.

## Implementation

- Added `docs/distribution/play-app-content.md` as the owner-facing App content
  declaration packet.
- Added `docs/distribution/play-app-content.json` as the checked machine
  contract for package name, Play submission status, ads, app access, target
  audience, content rating notes, Data safety, UGC, generated content,
  sensitive permissions, evidence paths, source URLs, and owner actions.
- Added `tools/play_app_content_packet_check.py` to validate the packet against
  `app/build.gradle.kts`, Fastlane metadata, privacy docs, Data safety matrix,
  owner action rows, and evidence paths.
- Added focused tests for the live packet plus package mismatch, missing
  evidence, child target age, missing UGC owner action, and sensitive
  permission/Data safety drift.
- Wired the packet check into verify and release workflows before Android setup
  or signed APK assembly.
- Updated release dry-run, release signing, supply-chain, and workflow security
  policy docs for the new preflight.
