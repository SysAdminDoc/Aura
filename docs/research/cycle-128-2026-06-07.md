# Cycle 128 Research - Network Endpoint Inventory Runbook

## Goal

Create a checked inventory for app network surfaces so new hard-coded hosts
cannot enter provider, service, or remote API code without endpoint/auth/cache
review.

## Local Evidence

- Retrofit providers are declared in `AppModule.kt` and the `data/remote`
  interfaces.
- Provider repositories and services also construct literal external URLs for
  SoundCloud streams, YouTube extraction, bundled Freesound references, Bing
  media URLs, Audius source pages, and Aura collection import links.
- Firebase community features use SDK/project-config-derived hosts that do not
  appear as literal Kotlin URLs but still need release review coverage.
- `network_security_config.xml` still permits cleartext for `ccmixter.org`,
  which makes endpoint inventory useful before the separate cleartext release
  gate.

## Implementation

- Added `docs/security/network-endpoints.json` as the reviewed machine-readable
  endpoint inventory.
- Added `docs/security/network-endpoints.md` as the release-review runbook with
  host, auth location, data sent, cache/rate/fallback, kill-switch, and owner
  rows for every current endpoint surface.
- Added `tools/network_endpoint_inventory_check.py` to validate inventory
  schema, Markdown coverage, source roots, and literal HTTP(S) hosts in
  network-facing Kotlin source.
- Added `test/tools/network_endpoint_inventory_check_test.py` with live-repo
  coverage plus negative tests for unreviewed hosts, missing endpoint fields,
  and stale docs.
- Wired `.github/workflows/verify.yml` to run the endpoint inventory scanner
  before Android setup.
- Updated `docs/distribution/supply-chain.md`, `ROADMAP.md`, `COMPLETED.md`,
  `CHANGELOG.md`, and loop state.

## Verification

Result: passed. The scanner found 19 reviewed literal hosts across 15 endpoint
surfaces, and the full lightweight tool suite passed with 138 tests.

## Remaining Risk

- Provider-returned media URLs can introduce CDN hosts that are not literal
  source strings. The runbook captures the known hard-coded hosts and provider
  media categories, but not every runtime CDN redirect.
- Firebase SDK hosts are project/config derived and are tracked in the manifest
  as release-review surfaces, not as literal Kotlin strings.
- The separate cleartext release gate for `ccmixter.org` remains open.
