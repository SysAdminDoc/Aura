# Cycle 156 research - live background diagnostics

## Goal

Add the first live Settings diagnostics receipt for Aura background work by
reading current WorkManager unique-work state and Android Data Saver posture on
device.

## Local evidence

- `SettingsScreen` already has a local-only Diagnostics section with crash
  bundle and source diagnostics dialogs.
- `SettingsViewModel` already refreshes local diagnostic state on the IO
  dispatcher and exposes it through `StateFlow`.
- Aura's current background-work unique names are `auto_wallpaper`,
  `daily_wallpaper`, `weather_update`, `aura_originals_download`, and
  `rotation_trigger_oneshot`.
- `AndroidManifest.xml` already declares `ACCESS_NETWORK_STATE`, which is
  required for active metered-network checks.

## Source-backed Android notes

- WorkManager exposes unique-work status through
  `getWorkInfosForUniqueWork(uniqueWorkName)` and observable variants.
- Android Data Saver guidance points apps at `ConnectivityManager` for active
  metered-network state and restricted-background status.
- `ConnectivityManager.RESTRICT_BACKGROUND_STATUS_ENABLED` means background data
  is restricted for the app; disabled or whitelisted states still need metered
  network awareness for larger transfers.

## Implementation decision

Added `BackgroundWorkDiagnosticsReader` as an injectable reader so the Android
implementation can call WorkManager and `ConnectivityManager`, while JVM tests
can use a fake reader without WorkManager test infrastructure. Settings now has
a `Background work` diagnostics dialog showing:

- the active metered/unmetered state;
- Data Saver restricted-background status;
- one row per unique work name;
- WorkInfo state counts, record counts, max run attempts, and read errors.

The crash/support bundle remains an inferred static support context for now.
Persisted last success/failure/error receipts still need worker execution
instrumentation before support can tell "deferred" from "ran and failed."

## Remaining work

- Persist last success UTC, last failure UTC, and last error class for each
  worker.
- Add user-actionable deferral text for no network, unmetered unavailable, low
  battery, missing notification/location permissions, expedited quota downgrade,
  and KEEP coalescing.
- Decide whether to merge a live Settings diagnostics snapshot into the copied
  support bundle.
