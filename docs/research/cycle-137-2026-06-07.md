# Cycle 137 - Prompt Metadata Retention Cleanup

## Scope

Cycle 137 closed the generated wallpaper prompt metadata retention and deletion
policy item. Owner-gated live callable evidence, hosted deletion URL
publication, production Firebase dry runs, GitHub security settings evidence,
and signed release dry-run evidence remained unavailable locally.

## Local Evidence

Before this pass, generated wallpapers copied prompt-derived text into two local
places:

- `AiWallpaperRepository.generate()` mined up to five prompt words into
  generated wallpaper tags.
- `AiWallpaperViewModel.saveToFavorites()` stored `AI: ${prompt.take(60)}` as
  the favorite name.

That meant sensitive prompt words could remain searchable in Room favorites even
after the user no longer viewed the generated image.

## Implementation

- Stopped mining prompt words into generated wallpaper tags. New generated rows
  keep only `ai-generated` and the selected style preset.
- Saved generated favorites with the generic `Generated wallpaper` name.
- Sanitized generated favorite tags at save time so only reviewed non-prompt
  generated tags are persisted.
- Added generated-file cleanup for AI-generated wallpaper removals from the
  wallpaper favorite toggle.
- Added generated-file cleanup after the Favorites bulk-delete Undo window
  closes without restore.
- Updated generated wallpaper privacy docs and the main privacy policy with the
  prompt metadata and deletion behavior.
