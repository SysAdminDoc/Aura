# Cycle 68 - Community Block User Policy

## Scope

Cycle 68 adds the first block-user data contract for Aura community surfaces:
typed Android policy helpers, private RTDB paths, emulator rules coverage, and
runbook documentation.

## Primary Sources

- Google Play User Generated Content policy:
  https://support.google.com/googleplay/android-developer/answer/9876937
- Google Play moderation requirements for UGC apps:
  https://support.google.com/googleplay/android-developer/answer/12923286
- Firebase Realtime Database Security Rules:
  https://firebase.google.com/docs/database/security

## Local Evidence

- Aura already has public community uploads, private report intake, admin
  hide/restore actions, status-filtered moderation review, rights takedown
  receipts, deletion tombstones, and quota/callable contracts.
- `database.rules.json` did not yet reserve a user block list or admin reverse
  index.
- `CommunityQuotaPolicies` did not yet include block/unblock writes as a
  callable quota surface.
- The older roadmap continuation summary still listed deletion retention policy
  as open after Cycle 67 completed it.

## Implementation

- Added `CommunityBlockPolicy.kt` with block reasons, private block-list path
  helpers, reverse-index path helpers, and a multi-path update builder.
- Added `CommunityBlockPolicyTest` for sanitized path generation and self-block
  rejection.
- Added `user_blocks` to `CommunityQuotaPolicies` with the
  `setCommunityUserBlock` callable contract and final write paths for the
  private list plus admin reverse index.
- Reserved `/community_user_blocks/{blockerUid}/{blockedUid}` and
  `/community_blocked_by/{blockedUid}/{blockerUid}` in RTDB rules.
- Added emulator coverage for anonymous/cross-user rejection, private list
  reads, admin reverse-index reads, mismatched payload rejection, self-block
  rejection, and unblock deletes.
- Added `docs/community-block-user-policy.md` and linked it from reporting,
  quota, callable, rules, backend, roadmap, changelog, completed, and loop
  state docs.
- Cleaned stale roadmap continuation text that still listed deletion retention
  as open.
