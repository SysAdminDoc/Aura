# Cycle 47 - Pexels Enhancement Guardrails

## Scope

Cycle 47 closes the Pexels usage guardrail item from `ROADMAP.md`: Pexels must
remain an enhancement source in Aura's mixed wallpaper and video-wallpaper
catalogs, not the sole first-run inventory.

## Source Check

- Pexels help article "Can I use the API as a wallpaper app?", checked
  2026-06-06:
  https://help.pexels.com/hc/en-us/articles/4405588861721-Can-I-use-the-API-as-a-wallpaper-app
- Pexels API documentation, checked 2026-06-06:
  https://www.pexels.com/api/documentation/

The Pexels wallpaper-app guidance says standalone wallpaper/gallery replication
is not allowed and frames allowed usage as an enhancement to a product with a
different primary purpose. The API documentation asks API users to show Pexels
links and credit photographers where possible.

## Local Evidence

- `WallpaperRepository.getDiscover()` previously requested Wallhaven, Pixabay,
  and Pexels in parallel. Disabled Pexels returned an empty source result, but
  the code did not encode that Pexels-only output must not become the whole
  Discover feed.
- `VideoWallpapersViewModel.load()` already tried Pexels, Pixabay, Reddit, and
  YouTube independently. Disabled Pexels skipped API work, but a successful
  Pexels-only batch could still become the entire video-wallpaper feed.
- Pexels photo mapping already includes `ContentSource.PEXELS`,
  `sourcePageUrl`, and `uploaderName`, and wallpaper cards/details display
  source and creator context through existing shared components.

## Implementation

- Added `keepPexelsAsDiscoverEnhancement()` to filter mixed Discover source
  results before merge. Pexels rows are kept only when at least one non-Pexels
  source returned visible inventory.
- Added `keepPexelsVideosAsEnhancement()` to apply the same enhancement-only
  rule to video-wallpaper batches before orientation filtering and ranking.
- Kept the existing default-on Pexels provider switch. Disabled mode continues
  to skip Pexels API calls before bundled key reads and records disabled source
  diagnostics.
- Added focused unit tests proving:
  - Pexels-only Discover results are dropped.
  - Pexels Discover rows remain when Wallhaven/Pixabay-style base inventory is
    present.
  - Disabled-Pexels Discover returns Wallhaven/Pixabay fallback inventory and
    does not call Pexels APIs.
  - Pexels photo rows keep photographer and source-page fields.
  - Pexels-only video batches are dropped, while mixed Pexels/Pixabay batches
    remain.
