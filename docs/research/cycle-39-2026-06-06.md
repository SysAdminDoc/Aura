# Cycle 39 - Pexels and Pixabay Source Switches

Date: 2026-06-06

## Research

Pexels and Pixabay both support Aura's richer wallpaper experience, but neither
should be treated as an unavoidable runtime dependency. Pexels' current API
guidance says wallpaper/gallery replication is not allowed and that Pexels
content should enhance a broader product experience. Pixabay's current API docs
require visible source context in results, document rate-limit headers, require
24-hour request caching, and prohibit systematic mass downloads.

Aura already short-circuited Pexels and Pixabay when effective API keys were
blank, but release builds can include bundled default keys. A policy or
distribution profile therefore needs explicit source-enabled flags that stop API
work before keys are read.

## Local Evidence

- `WallpaperRepository.kt` used Pexels and Pixabay in Discover, source tabs,
  style-biased Discover calls, and wallpaper search.
- `VideoWallpapersViewModel.kt` attempted Pexels and Pixabay video jobs in the
  shared video wallpaper load path.
- `SettingsScreen.kt` exposed Pexels and Pixabay API key editors but no source
  switches.
- `AutoWallpaperWorker.kt` and the widget shortcut could still attempt Pixabay
  independently of visible wallpaper browsing.

## Decision

Add default-on `pexels_provider_enabled` and `pixabay_provider_enabled`
preferences so existing installs keep their current behavior, then guard every
active Pexels/Pixabay entry point before API key reads or remote calls.
Pixabay remains partial in the broader policy matrix because TTL/rate-limit
enforcement is a separate requirement from source disablement.

## Implementation

- Added Pexels and Pixabay provider-enabled preferences and Settings switches.
- Gated `WallpaperRepository` Pexels/Pixabay photo calls before key reads,
  including Discover, search, style-biased Discover, and source-tab loads.
- Updated Wallpapers to hide disabled Pexels/Pixabay tabs and redirect stale
  selections to Discover.
- Updated Video Wallpapers to skip disabled Pexels/Pixabay video jobs before
  key reads.
- Updated auto-rotation source pickers and workers so disabled Pixabay is not
  offered for new rotation choices and does not retry indefinitely when already
  selected.
- Updated provider runtime-control docs to mark Pexels source disablement
  covered and keep Pixabay TTL/rate-limit guards open.

## Verification Plan

- Run focused JVM tests for Wallpapers, Settings, video wallpaper helpers,
  source metrics, and provider runtime controls.
- Run release-compliance Python checks to keep existing legal artifact gates
  green.
- Run `git diff --check` and the changed-line attribution scan before commit.
