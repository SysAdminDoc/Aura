# Cycle 135 - Stability Key Policy Sentinel

## Scope

Cycle 135 closed the BYO Stability key hardening item by making the existing
provider credential policy guard explicitly enforce Stability's paid-sensitive
posture. Owner-gated live callable, hosted deletion URL, production Firebase,
GitHub settings, and signed-release dry-run evidence remained unavailable
locally.

## Security Check

Aura already had broad provider credential release, APK scan, storage,
backup/device-transfer, diagnostics, and report-redaction coverage. The
remaining gap was that Stability's paid-sensitive classification was implied by
the matrix and a count assertion instead of being checked by exact credential
identity.

Android's Keystore documentation describes non-exportable key material and
hardware-backed extraction resistance when supported. Aura continues to record
the current no-Keystore decision for optional, user-entered provider values,
with blank public release defaults, backup/device-transfer exclusion, explicit
Clear control, diagnostics redaction, and a release guard that fails on bundled
provider values.

## Implementation

- Extended `tools/provider_credential_storage_check.py` with a
  `stability-ai-key` sentinel requirement.
- The guard now fails if Stability is no longer a DataStore-backed
  `paidSensitiveSecret`, if `STABILITY_AI_KEY` / `stability.ai.key` no longer
  defaults blank for public releases, if `stability.ai.key` redaction coverage
  is missing, or if explicit Clear control is no longer documented.
- Added focused Python coverage for Stability classification drift and missing
  `stability.ai.key` redaction coverage.
- Added `stability.ai.key` to the machine-readable policy redaction terms and
  support diagnostics runbook.
- Updated security/supply-chain docs, roadmap, changelog, completion, and loop
  state.

## Verification

- Focused provider credential tests passed:
  `py -3 -m unittest discover -s test/tools -p 'provider_credential*_test.py'`.
- Live provider credential storage policy passed:
  `py -3 tools\provider_credential_storage_check.py --policy docs\security\provider-credential-storage.json --repo-root .`.
- Provider credential release guard passed with blank release-style local
  properties, including `stability.ai.key`.
