# Cycle 60 - Rights Takedown Receipts

## Scope

Cycle 60 adds private admin rights-confirmed takedown receipts for community
sound and wallpaper reports that can be tied to current upload deletion handles.

## Implementation

- Added `CommunityTakedownAction`, takedown upload helpers, and
  `buildCommunityTakedownReceiptPayload()` to keep receipt payloads normalized.
- Updated `CommunityReportRepository.resolveReport()` so hiding a `RIGHTS`
  report for a community sound or wallpaper reads the current upload metadata
  and writes `/community_takedown_receipts/{reportId}` in the same
  multi-location update as the report resolution.
- The receipt records report ID, content ID, upload ID, metadata path, Storage
  path, uploader UID, resolver UID, timestamp, status, action, and note.
- Added `database.rules.json` validation for admin-only receipts. Rules require
  the receipt `storagePath` and uploader UID to match the current
  `/community_sounds/{uploadId}` or `/community_wallpapers/{uploadId}` metadata
  row.
- Extended the RTDB emulator suite with non-admin rejection, non-rights
  rejection, stale-handle rejection, mismatched-path rejection, and sound plus
  wallpaper success cases.
