# Cycle 46 Research: Saved Source Availability States

## Goal

Add a durable unavailable-source state for favorites and download history so
saved local copies can remain navigable when upstream provider content is
deleted, removed, hidden, or otherwise no longer safe to present as live source
content.

## Local Evidence

- `FavoriteEntity` stored source, source page, URLs, and offline paths, but it
  had no state for "the upstream source item is no longer available."
- `DownloadEntity` stored only local download history and did not preserve a
  source-unavailable state.
- `WallpaperDetailScreen` and `SoundDetailScreen` used source links/similar
  actions as normal live-source affordances when restored from saved records.
- `FavoriteEntity.toWallpaper()` ignored `offlinePath`, so a saved wallpaper
  could still prefer a remote URL even when an internal offline copy existed.
- Cycle 3 already captured the policy need: saved favorites/downloads must show
  unavailable/source-deleted state without deleting local copies.

## Decision

Add string-backed `sourceAvailability` and `sourceAvailabilityReason` metadata
to favorites and downloads. Keep the first implementation state small:
`AVAILABLE` and `SOURCE_UNAVAILABLE`. This avoids a brittle provider-specific
heuristic while giving provider sync, report, or takedown code a durable state
to set later.

## Implementation Notes

- Added `sourceAvailability` and `sourceAvailabilityReason` to `Wallpaper`,
  `Sound`, `FavoriteEntity`, and `DownloadEntity`.
- Added a v14-to-v15 Room migration and committed the generated v15 schema.
- Added DAO/repository/ViewModel hooks to mark and clear unavailable state.
- Updated favorite mapping so saved wallpaper details prefer `offlinePath` when
  present and carry source availability into domain models.
- Updated favorite export/import to preserve unavailable-source metadata.
- Updated `DownloadManager` and callers so new download records preserve the
  provider source name.
- Added Favorites and Downloads badges for source-unavailable records.
- Updated wallpaper detail and sound detail to show a source-unavailable warning
  and suppress live-source link/similar/share affordances when marked.

## Verification Plan

- Mapper tests cover unavailable-state round trip and offline-path preference.
- Favorites exporter validation tests cover import preservation of unavailable
  metadata.
- Downloads, Wallpapers, and Sounds ViewModel tests cover constructor and
  download-signature changes.
- Release-compliance Python checks remain unchanged and should still pass.
