# Cycle 27 - Release Compliance Artifact Dry Run

Date: 2026-06-06

## Objective

Prove that Aura's release compliance artifacts are packaged as one coherent bundle before workflow artifact upload or tagged GitHub Release publication.

## Local Evidence

- `.github/workflows/release.yml` already supports `workflow_dispatch` and only uploads to GitHub Releases when `github.ref` starts with `refs/tags/`.
- The release workflow now generates a signed release APK, `THIRD-PARTY-NOTICES.md`, `NATIVE-COMPLIANCE.md`, `SHA256SUMS.txt`, `RELEASE_NOTES.md`, `apksigner.txt`, and `aapt-badging.txt`.
- Cycle 24-26 gates validate generated notice drift, native payload drift, and curated high-risk dependency overlay coverage before the final release notes and artifact upload steps.
- The workflow did not yet have one final check proving the bundle is complete and internally consistent after all generated files exist.

## Implementation

Added `tools/release_artifact_bundle_check.py`.

The validator checks:

- Required files exist and are non-empty.
- The APK filename matches `versionName` and `versionCode`.
- `SHA256SUMS.txt` contains exactly the APK, `THIRD-PARTY-NOTICES.md`, and `NATIVE-COMPLIANCE.md`.
- Recorded SHA-256 digests match file bytes.
- `RELEASE_NOTES.md` contains the version, version code, APK name, APK SHA-256, third-party notices entry, native compliance entry, signing certificate line, attestation line, release build type, and `com.freevibe` package ID.
- `apksigner.txt` contains a signing certificate SHA-256 digest.
- `aapt-badging.txt` does not report `application-debuggable`.

Wired the validator into `.github/workflows/release.yml` after release-note generation and before `actions/upload-artifact` / tagged release upload.

Added `docs/distribution/release-dry-run.md` with:

- GitHub UI dry-run steps.
- GitHub CLI dry-run command.
- Explanation that manual branch runs upload workflow artifacts but do not create GitHub Releases.
- Bundle validator command and failure modes.
- Local parser/checksum smoke-test recipe.
