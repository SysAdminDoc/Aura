# Network Endpoint Inventory

This runbook is the reviewed inventory for app-initiated network surfaces.
`tools/network_endpoint_inventory_check.py` checks this file and
`docs/security/network-endpoints.json` against literal HTTP(S) hosts in the
network-facing Kotlin source roots.

## Guard

Run:

```powershell
py -3 tools\network_endpoint_inventory_check.py --inventory docs\security\network-endpoints.json --repo-root .
```

The guard scans:

- `app/src/main/java/com/freevibe/di`
- `app/src/main/java/com/freevibe/data/remote`
- `app/src/main/java/com/freevibe/data/repository`
- `app/src/main/java/com/freevibe/service`

Every literal HTTP(S) host in those roots must appear in
`docs/security/network-endpoints.json`. The Markdown runbook must mention every
endpoint ID and reviewed host.

## Review Notes

- Provider-returned media URLs can include CDN hosts that are not literal source
  strings. The manifest lists known direct hosts where Aura hard-codes them,
  plus provider-owned media categories in each row.
- `ccmixter-api` is HTTPS-only. `network_security_config.xml` no longer permits
  cleartext for `ccmixter.org`, and the release cleartext guard fails on new
  provider `http://` URL literals, OkHttp `.scheme("http")` builders, manifest
  cleartext enablement, or network-security cleartext exceptions.
- Firebase hosts are SDK/project-config derived. They are included for release
  review even when they are not literal Kotlin URL strings.
